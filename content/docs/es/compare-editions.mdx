---
title: "Comparar ediciones: Community, Cloud y Enterprise"
description: "Qué funciones tiene la Community Edition autoalojada de Customermates, cuáles solo Cloud y cuáles requieren un acuerdo Enterprise, con su licencia."
---

Customermates funciona de dos maneras: como Cloud, gestionado por Customermates, y como Community Edition, que usted aloja con Docker Compose. Los servicios que ninguna de las dos ediciones incluye, como el inicio de sesión único y la marca blanca, se acuerdan aparte en un acuerdo Enterprise. La página [Licencia](/docs/licence) explica las licencias, y la [página de precios](/pricing) es la fuente de verdad de los planes y precios. Esta página puede ir por detrás de una versión.

## ¿Qué funciones tiene cada edición? [#which-features-does-each-edition-have]

| Función | Community Edition (autoalojada) | Cloud |
|---|---|---|
| Quién la opera | Usted: Docker, PostgreSQL, TLS, actualizaciones y copias de seguridad | Customermates |
| Listas, registros, vistas, modelo de datos y paneles | Sí | Sí |
| Miembros, roles y permisos | Sí | Sí |
| Varios espacios de trabajo por inicio de sesión | Sí, sin facturación | Sí, cada uno con su plan |
| Importación y exportación de Excel | Sí | Sí |
| Registro de actividad | Sí | Sí |
| API REST, webhooks, MCP con su propio cliente de IA y n8n | Sí | Sí, los límites dependen del plan |
| Bandeja unificada para correo, LinkedIn, WhatsApp, Instagram y Telegram | No | Desde el plan Pro |
| Calendarios conectados | No | Desde el plan Pro |
| Mate, el asistente alojado, con créditos de IA alojados | No | Sí, el uso depende del plan |
| Rutinas que ejecuta Mate | No | Sí |
| Configuración del espacio de trabajo con IA en la incorporación | No | Sí |
| Compartir cuentas enteras | No | Desde el plan Business |
| Licencia | Sustainable Use License, gratuita para su propia empresa | Una suscripción con sus propios términos |

## ¿Qué no incluye la Community Edition? [#what-does-the-community-edition-not-include]

Una instancia autoalojada tiene el conjunto de funciones de Starter. Las funciones exclusivas de Cloud permanecen desactivadas, aunque además pague un plan de Cloud. La aplicación oculta lo que no corresponde: la barra lateral no muestra Bandeja ni Rutinas, y Ajustes no tiene la página Facturación. [Autoalojamiento](/docs/self-hosting#which-features-are-not-available-when-self-hosting) las lista por completo.

## ¿Qué requiere un acuerdo Enterprise? [#what-needs-an-enterprise-agreement]

Esto requiere un acuerdo escrito bajo la Customermates Enterprise License. Nada de ello forma parte de un plan.

| Qué | Estado |
|---|---|
| Inicio de sesión único | No integrado. Disponible como trabajo contratado. |
| Marca blanca | Mediante acuerdo. La marca de Customermates sigue visible. |
| Integrar Customermates en su propio producto | Mediante acuerdo. |
| Funciones Enterprise en una instancia autoalojada | Mediante acuerdo. Un plan de Cloud no las desbloquea. |
| Flujos contratados de agentes a medida y de datos de leads | No integrados. Disponibles como trabajo contratado. |

## ¿Cómo paso de una edición a otra? [#how-do-i-move-between-editions]

Los registros pasan entre Cloud y el autoalojamiento como libros de Excel, una lista cada vez. Migrar toda la plataforma es un proyecto que se diseña aparte. Para un acuerdo Enterprise, use la [página de contacto](/contact).
