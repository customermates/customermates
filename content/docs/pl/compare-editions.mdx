Customermates działa na dwa sposoby: jako Cloud, prowadzony przez Customermates, i jako Community Edition, którą hostujesz sam z Docker Compose. Usługi, których nie obejmuje żadna z edycji, takie jak jednokrotne logowanie i white label, ustala się osobno w umowie Enterprise. Strona [Licencja](/docs/licence) wyjaśnia licencje, a [strona z cennikiem](/pricing) jest źródłem prawdy o planach i cenach. Ta strona może nie nadążać za wydaniem.

## Jakie funkcje ma każda edycja? [#which-features-does-each-edition-have]

| Funkcja | Community Edition (hostowana samodzielnie) | Cloud |
|---|---|---|
| Kto ją prowadzi | Ty: Docker, PostgreSQL, TLS, aktualizacje i kopie zapasowe | Customermates |
| Listy, rekordy, widoki, model danych i pulpity | Tak | Tak |
| Członkowie, role i uprawnienia | Tak | Tak |
| Kilka przestrzeni roboczych na jeden login | Tak, bez rozliczeń | Tak, każda z własnym planem |
| Import i eksport Excel | Tak | Tak |
| Dziennik aktywności | Tak | Tak |
| REST API, webhooki, MCP z własnym klientem AI i n8n | Tak | Tak, limity zależą od planu |
| Formularze publiczne | Tak | Tak, limity zależą od planu |
| Automatyzacje | Tak | Tak, limity zależą od planu |
| Powiadomienia i e-maile z podsumowaniem | Tak | Tak |
| Przychodzące webhooki | Tak | Tak |
| Wspólna skrzynka dla poczty, LinkedIn, WhatsApp, Instagrama i Telegramu | Nie | Od planu Pro |
| Połączone kalendarze | Nie | Od planu Pro |
| Planowanie spotkań i strony rezerwacji | Nie | Od planu Pro |
| Mate, hostowany asystent, z hostowanymi kredytami AI | Nie | Tak, zużycie zależy od planu |
| Rutyny uruchamiane przez Mate | Nie | Tak |

## Czego nie zawiera Community Edition? [#what-does-the-community-edition-not-include]

Instancja hostowana samodzielnie ma zestaw funkcji planu Starter. Funkcje tylko dla Cloud pozostają wyłączone, nawet jeśli dodatkowo płacisz za plan Cloud. Aplikacja ukrywa to, co nie dotyczy: pasek boczny nie pokazuje Skrzynki ani Rutyn, a Ustawienia nie mają strony Rozliczenia. [Self-hosting](/docs/self-hosting#which-features-are-not-available-when-self-hosting) wymienia je w całości.

## Co wymaga umowy Enterprise? [#what-needs-an-enterprise-agreement]

Wymagają one pisemnej umowy na podstawie Customermates Enterprise License. Żadna z tych rzeczy nie należy do planu.

| Co | Stan |
|---|---|
| Jednokrotne logowanie | Nie jest wbudowane. Możliwe jako praca zlecona. |
| White label | Na podstawie umowy. Branding Customermates pozostaje widoczny. |
| Osadzanie Customermates we własnym produkcie | Na podstawie umowy. |
| Funkcje Enterprise w instancji hostowanej samodzielnie | Na podstawie umowy. Plan Cloud ich nie odblokowuje. |
| Zlecone przepływy dla własnych agentów i danych o leadach | Nie są wbudowane. Możliwe jako praca zlecona. |

## Jak przejść z jednej edycji do drugiej? [#how-do-i-move-between-editions]

Rekordy przechodzą między Cloud a self-hostingiem jako skoroszyty Excel, jedna lista naraz. Migracja całej platformy to osobno zaprojektowany projekt. W sprawie umowy Enterprise skorzystaj ze [strony kontaktowej](/contact).
