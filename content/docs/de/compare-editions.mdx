title: "Editionen vergleichen: Community, Cloud und Enterprise"
description: "Welche Funktionen die selbst gehostete Community Edition von Customermates hat, welche nur Cloud bietet und welche eine Enterprise-Vereinbarung brauchen."
---

Customermates läuft auf zwei Arten: als Cloud, von Customermates betrieben, und als Community Edition, die Sie selbst mit Docker Compose hosten. Leistungen, die keine der beiden Editionen enthält, etwa Single Sign-on und White-Label, werden gesondert in einer Enterprise-Vereinbarung geregelt. Die Seite [Lizenz](/docs/licence) erklärt die Lizenzen, und die [Preisseite](/pricing) ist maßgeblich für Tarife und Preise. Diese Seite kann einem Release hinterherhinken.

## Welche Funktionen hat jede Edition? [#which-features-does-each-edition-have]

| Funktion | Community Edition (selbst gehostet) | Cloud |
|---|---|---|
| Wer betreibt es | Sie: Docker, PostgreSQL, TLS, Updates und Backups | Customermates |
| Listen, Datensätze, Ansichten, Datenmodell und Dashboards | Ja | Ja |
| Mitglieder, Rollen und Berechtigungen | Ja | Ja |
| Mehrere Workspaces pro Login | Ja, ohne Abrechnung | Ja, jeder mit eigenem Tarif |
| Excel-Import und -Export | Ja | Ja |
| Aktivitätsprotokoll | Ja | Ja |
| REST-API, Webhooks, MCP mit Ihrem eigenen KI-Client und n8n | Ja | Ja, Limits je nach Tarif |
| Öffentliche Formulare | Ja | Ja, Limits je nach Tarif |
| Automatisierungen | Ja | Ja, Limits je nach Tarif |
| Agent-Schritt in Automatisierungen mit Ihrem eigenen KI-Schlüssel | Ja | In bezahlten Tarifen |
| Agent-Schritt auf Ihrem eigenen Runner | Ja | Ja |
| Benachrichtigungen und E-Mail-Zusammenfassungen | Ja | Ja |
| Eingehende Webhooks | Ja | Ja |
| Einheitliches Messaging über alle Kanäle | Nein | Ab dem Pro-Tarif |
| Kalendersynchronisierung | Nein | Ab dem Pro-Tarif |
| Termine planen und Buchungsseiten | Nein | Ab dem Pro-Tarif |
| Mate, der gehostete Assistent, mit gehosteten KI-Credits | Nein | Ja, Nutzung je nach Tarif |
| Routinen, die Mate ausführt | Nein | Ja |
| KI-Einrichtung des Workspace im Onboarding | Nein | Ja |
| Freigabe ganzer Konten | Nein | Ab dem Business-Tarif |
| Lizenz | Sustainable Use License, für das eigene Unternehmen kostenlos | Ein Abonnement mit eigenen Bedingungen |

## Was enthält die Community Edition nicht? [#what-does-the-community-edition-not-include]

Eine selbst gehostete Instanz hat den Funktionsumfang von Starter. Die Funktionen, die nur Cloud bietet, bleiben aus, auch wenn Sie zusätzlich einen Cloud-Tarif bezahlen. Die App blendet aus, was nicht zutrifft: Die Seitenleiste zeigt weder Posteingang noch Routinen, und die Einstellungen haben keine Seite Abrechnung. [Self-Hosting](/docs/self-hosting#which-features-are-not-available-when-self-hosting) listet sie vollständig auf.

## Was braucht eine Enterprise-Vereinbarung? [#what-needs-an-enterprise-agreement]

Dafür ist eine schriftliche Vereinbarung nach der Customermates Enterprise License nötig. Nichts davon ist Teil eines Tarifs.

| Was | Stand |
|---|---|
| Single Sign-on | Nicht eingebaut. Als beauftragte Arbeit möglich. |
| White-Label | Nach Vereinbarung. Das Customermates-Branding bleibt sichtbar. |
| Customermates in ein eigenes Produkt einbetten | Nach Vereinbarung. |
| Enterprise-Features auf einer selbst gehosteten Instanz | Nach Vereinbarung. Ein Cloud-Tarif schaltet sie nicht frei. |
| Beauftragte Workflows für eigene Agenten und Lead-Daten | Nicht eingebaut. Als beauftragte Arbeit möglich. |

## Wie wechsle ich zwischen den Editionen? [#how-do-i-move-between-editions]

Datensätze wandern als Excel-Arbeitsmappen zwischen Cloud und Self-Hosting, eine Liste nach der anderen. Eine Migration der ganzen Plattform ist ein eigenes, gesondert geplantes Projekt. Für eine Enterprise-Vereinbarung nutzen Sie die [Kontaktseite](/contact).
