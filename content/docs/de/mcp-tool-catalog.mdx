49 Tools für Entitäten, Widgets, Webhooks, Custom Columns, Admin und Messaging (Preview). Jedes destruktive Tool ist geflaggt und startet die Beschreibung mit `IRREVERSIBLE`. Jedes Tool, das ein Relationship-Array ersetzt, warnt und verweist auf `link_entities` / `unlink_entities`.

## Wie diese Seite zu lesen ist

Drei Flags pro Tool:

- **Read**: keine Mutation.
- **Destructive**: nicht rückgängig.
- **Idempotent**: zweimal derselbe Call = derselbe State.

Das volle JSON-Schema jedes Tools liegt live an `POST /api/v1/mcp` mit `method: "tools/list"`.

## Per-Entity Create und Update

Ein Create und ein Update pro Entity. Create bis 100; Update bis 100.

| Entity | Create | Update |
|---|---|---|
| Contact | `create_contacts` | `update_contacts` |
| Organization | `create_organizations` | `update_organizations` |
| Deal | `create_deals` | `update_deals` |
| Service | `create_services` | `update_services` |
| Task | `create_tasks` | `update_tasks` |

Die Update-Tools akzeptieren Partial-Payloads. `null` auf Relationship-Arrays wird abgelehnt, mit Hinweis auf `link_entities` / `unlink_entities`.

## Custom Columns

| Tool | Read | Destructive | Zweck |
|---|---|---|---|
| `list_custom_columns` | ✓ | | Alle Custom Columns, optional nach Entity-Typ. Liefert `{id, label, type, entityType, options}`. |
| `upsert_custom_column` | | | Anlegen (`id` weglassen) oder aktualisieren (bestehende `id` übergeben). Ein Tool deckt alle zehn Typen über den `type`-Diskriminator und per-Type-`options` ab. `type` und `entityType` sind beim Update unveränderlich. Idempotent. |
| `delete_custom_column` | | ✓ | IRREVERSIBLE. Löscht Spalte und alle gespeicherten Werte. Widgets darauf können brechen. |

Die zehn Spaltentypen (`plain`, `date`, `dateTime`, `dateRange`, `dateTimeRange`, `currency`, `singleSelect`, `link`, `email`, `phone`) werden alle von `upsert_custom_column` abgedeckt. Um den Typ einer bestehenden Spalte zu ändern, lösche sie und lege eine neue an.

Die Messaging-Oberfläche ist Preview: Diese 7 Tools sind heute live über MCP, aber das Feature entwickelt sich noch, also als Early Access behandeln.

| Tool | Read | Sendet | Zweck |
|---|---|---|---|

| `send_chat_message` | | ✓ | Echte Nachricht in einen bestehenden Chat-Thread senden (LinkedIn/WhatsApp/etc.). Braucht `threadId`, `text`. |

## Eingebaute Sicherheitsregeln

- **Null auf Relationship-Array** serverseitig abgelehnt mit Hinweis auf `link_entities` / `unlink_entities`.
- **`type` und `entityType` einer Custom Column sind beim Update unveränderlich.** `upsert_custom_column` übernimmt sie aus der bestehenden Spalte; für einen Typwechsel löschen und neu anlegen.
- **Jedes `delete_*`** hat `destructiveHint: true` und Beschreibung beginnt mit `IRREVERSIBLE`.
- **Jedes Enum-Feld** listet gültige Werte inline, damit schwächere Modelle keine externen Typen auflösen müssen.
- **Jedes `filters`-Feld** enthält ein konkretes JSON-Beispiel.
