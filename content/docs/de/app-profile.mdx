Customermates ist ein Open-Source-CRM, AI-native gebaut. Diese Seite dokumentiert den **Profil**-Screen der Web-App, für Menschen und für AI-Agents, die die UI steuern.

## Zweck

Das Profil bündelt Ihre persönlichen Workspace-Einstellungen: alles, was an Ihnen als User hängt, nicht an der Company. Drei Tabs decken Ihre Einstellungen (ein Formular für Identität und Präferenzen: Name, Land, Avatar, Theme, Sprache), API-Keys für MCP- und REST-Clients sowie die Messaging-Konten ab, aus denen die Inbox gespeist wird. Änderungen hier betreffen nur Ihren eigenen Account.

## URL

`/profile/settings`

URLs sind locale-präfixiert, zum Beispiel `https://customermates.com/en/profile/settings`. Jeder Tab hat eine eigene Route: `/profile/settings`, `/profile/api-keys`, `/profile/connected-accounts`.

## Wichtige Aktionen

| Aktion | Wo | Anchor id | Was passiert |
|---|---|---|---|
| Zum Profil wechseln | App-Sidebar | `#nav-profile` | Öffnet /profile/settings |
| Tab Einstellungen | Sidebar-Unterpunkt | `#nav-profile-settings` | Identität (Name, Land, Avatar) und Präferenzen (Theme, Sprache) in einem Formular |
| Einstellungen speichern / zurücksetzen | Formular-Footer | `#profile-settings-save` / `#profile-settings-reset` | Speichert oder verwirft (Reset erscheint bei ungespeicherten Änderungen) |
| Tab API Keys | Sidebar-Unterpunkt | `#nav-profile-api-keys` | Keys für MCP-/REST-Clients verwalten |
| API-Key hinzufügen | API-Keys-Karte | `#profile-api-keys-generate` | Öffnet einen Assistenten für einen Standard-Key oder eine geführte KI-Verbindung |
| Standard-Key anlegen | Assistent zum Hinzufügen | `#api-key-save` | Erscheint nach Standard-API-Key; der Key wird einmal angezeigt und muss sofort kopiert werden |
| KI-Client verbinden | Assistent zum Hinzufügen | none | Claude, ChatGPT, Codex, Cursor oder Gemini für eine clientspezifische Einrichtung wählen |
| Key widerrufen | Key-Zeile | none | Zeilen-Button mit Label Revoke |
| Tab Verbundene Konten | Sidebar-Unterpunkt | `#nav-profile-connected-accounts` | Messaging-Konten für die Inbox |
| Konto verbinden | Karten-Header | `#profile-connected-accounts-connect` | Öffnet das Hosted-Auth-Fenster (E-Mail, LinkedIn, WhatsApp, Instagram, Telegram) |
| Konto / Ordner verwalten | Klick auf Konto-Zeile | none | Öffnet das Konto-Modal (Ordnerauswahl, Resync) |

## Tipps für Agents

- Steuerelemente über die stabilen Ids aus der Tabelle finden, zum Beispiel trifft der CSS-Selektor `#profile-api-keys-generate` den Generieren-Button. Die Ids sind stabil; sichtbare Labels und Layout sind es nicht.
- Zeilen tragen nie Ids. Datensätze über ihre URL öffnen oder auf Entity-Seiten über den Drawer-Deep-Link `?open=<entityType>:{id}`. Die Profil-Tabs sind einfache Routen, also per Tab-URL navigieren und in Zeilen die sichtbaren Buttons nutzen (z.B. **Revoke**) oder die Zeile anklicken.
- Wenn ein MCP-Tool existiert, nutzen Sie es statt zu klicken, siehe [MCP](/docs/mcp). Die UI zu steuern lohnt nur für die wenigen Aktionen ohne Tool, etwa das Verbinden eines Messaging-Kontos.
- Das Modal zum Hinzufügen bietet zuerst einen Standard-Key mit Name und Ablaufdatum sowie fünf geführte KI-Verbindungen an. Claude und ChatGPT können den benutzerdefinierten Connector nutzen; lokale Claude-Clients, Codex, Cursor und Gemini erstellen einen Key und zeigen nur den passenden Einrichtungsausschnitt.
- Ein generierter API-Key wird genau einmal angezeigt, unabhängig davon, ob er über `#api-key-save` oder eine Schnellverbindung erstellt wurde. Kopieren Sie den angezeigten Key oder Einrichtungsausschnitt im selben Schritt; der Key lässt sich nicht erneut im Klartext anzeigen.
- Konto verbinden öffnet ein separates Hosted-Auth-Fenster. Rechnen Sie mit einem Popup, nicht mit In-Page-Navigation.
