---
title: "Routine-Rezepte für kleine Agenturen"
description: "Vier Prompts für Mate oder eine Routine. Jeder erledigt die Arbeit an den Datensätzen und lässt alles für Kunden als Entwurf liegen, den Sie senden."
---

Jedes Rezept hat denselben Aufbau: ein Auslöser, die Arbeit an den Datensätzen, die der Agent erledigt, und eine Sache, die Sie freigeben. Nichts geht an einen Kunden, bevor Sie auf **Senden** klicken. Routinen laufen in Customermates Cloud; Auslöser, Limits und was ein Lauf darf, stehen unter [Routinen](/docs/app-routines).

## 1. Nach dem Kundengespräch [#after-the-client-call]

**Wo:** in einem Chat mit Mate (Cmd/Ctrl+J), direkt nach dem Gespräch. Fügen Sie Ihre Notizen ein oder hängen Sie ein Foto davon an.

```
Füge meine Gesprächsnotizen (Text oder Foto) dem passenden Deal hinzu, setze den nächsten Schritt und schreibe die Follow-up-E-Mail an den Kontakt. Speichere sie als Entwurf. Nicht senden.
```

**Sie geben frei:** den Follow-up-Entwurf in Ihrem [Posteingang](app:inbox).

## 2. Eine LinkedIn-Antwort kommt an [#a-linkedin-reply-comes-in]

**Wo:** [Routinen](app:routines) > [Hinzufügen](app:routines?focus=add) > **Wenn sich etwas ändert** > das Ereignis **Nachricht empfangen** (`messaging.message.received`). Ihr LinkedIn-Konto muss unter [Kanäle](app:settings/channels) verbunden sein.

```
Wenn diese Nachricht über LinkedIn kam: Füge das Gesagte als Notiz beim Kontakt hinzu, setze den nächsten Schritt und speichere eine kurze Antwort als Entwurf im Verlauf. Niemals senden.
```

**Sie geben frei:** den Antwortentwurf im LinkedIn-Verlauf.

## 3. Ein Kunde bestellt per WhatsApp [#a-client-orders-on-whatsapp]

**Wo:** [Routinen](app:routines) > [Hinzufügen](app:routines?focus=add) > **Wenn sich etwas ändert** > das Ereignis **Nachricht empfangen** (`messaging.message.received`), mit verbundenem WhatsApp. Ihr Workspace braucht eine Liste für Projekte oder Aufträge.

```
Wenn diese WhatsApp-Nachricht neue Arbeit anfragt: Lege ein Projekt an, verknüpft mit dem Kunden, mit dem, was er möchte und bis wann er es braucht, und speichere eine Antwort als Entwurf. Niemals senden.
```

**Sie geben frei:** das neue Projekt und den Antwortentwurf.

## 4. Montag 08:00 [#monday-0800]

**Wo:** [Routinen](app:routines) > [Hinzufügen](app:routines?focus=add) > **Nach Zeitplan** > **Wöchentlich**, Montag, 08:00.

```
Fasse meine offene Pipeline zusammen: Summe, gewichtet, größter Deal. Liste Deals ohne Antwort seit 14 Tagen auf und speichere für jeden einen kurzen Nachfass-Entwurf. Schick mir die Zusammenfassung per E-Mail.
```

**Sie geben frei:** jeden Nachfass-Entwurf; die Zusammenfassung geht nur an Sie.

## Warum Entwürfe [#why-drafts]

Routinen dürfen Nachrichten ohne Rückfrage senden (siehe [Was eine Routine ohne Freigabe darf](/docs/app-routines#what-a-routine-may-do-without-approval)). Die Prompts oben sagen bewusst „Niemals senden“, damit jede Nachricht an einen Kunden auf Sie wartet.
