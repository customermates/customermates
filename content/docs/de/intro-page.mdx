Customermates ist ein Open-Source-CRM mit einem nativen MCP-Endpoint. Claude, ChatGPT, Cursor und jeder andere Client, der das Model Context Protocol spricht, liest und schreibt Ihr CRM direkt, ganz ohne Copy-Paste.

## Client wählen und loslegen

| Ihre KI | Volles Setup auf einer Seite |
|---|---|
| Claude & ChatGPT (Custom Connector) | [Mit einem Custom Connector verbinden](/docs/connect-custom-connector) |
| Claude Code | [Claude Code verbinden](/docs/connect-cli#claude-code) |
| Cursor | [Cursor verbinden](/docs/connect-cli#cursor) |
| Beliebiger MCP-Client | [MCP-Übersicht](/docs/mcp) |

Jede Seite ist in sich abgeschlossen: die Verbindungsschritte und Ihre ersten Kommandos. Der Server brieft Ihren Client automatisch beim Verbinden, Sie müssen also nicht zwischen Seiten wechseln.

Für einen Durchlauf mit Webhook und erster KI-Interaktion siehe [Quickstart](/docs/quickstart).

## Was Customermates ist

Ein CRM mit fünf Record-Typen (Contacts, Organizations, Deals, Services, Tasks), Custom Columns, Tabellen- und Kartenansichten und Dashboards, plus:

- **Nativer MCP-Endpoint** unter `/api/v1/mcp`, damit ein MCP-Client CRM-Operationen ohne Plugin entdeckt und aufruft.
- **Open Source** unter AGPLv3. Enterprise-Komponenten stehen unter einer separaten kommerziellen Lizenz. Self-Hosting oder die Managed Cloud.
- **EU-gehostete und DSGVO-konforme** Managed-Version.
- **Webhooks** mit signierten Payloads, Retries und Delivery-Log.
- **OpenAPI-3.1**-Spezifikation für die volle REST-Oberfläche unter `/api/v1/openapi`.

## Vier Wege, wie Customermates mit Ihrem Stack spricht

| Ich will | Nehmen Sie |
|---|---|
| Einen MCP-Client das CRM im Gespräch aktualisieren lassen | [MCP](/docs/mcp) |
| Eine Custom-Integration in Code bauen | [OpenAPI](/docs/openapi) |
| Auf CRM-Änderungen in Slack, einem Sequencer, BI oder Ihrem Warehouse reagieren | [Webhooks](/docs/webhooks) |
| Workflows visuell ohne Code komponieren | [n8n](/docs/n8n) |

Alle vier authentifizieren sich mit einem API-Key. MCP-Clients wie Claude und ChatGPT können sich auch per OAuth ohne Key verbinden. Siehe [API-Keys](/docs/api-keys).

## Design-Ansatz

Customermates behandelt den KI-Client als First-Class-User. Tools sind imperativ benannt, Fehler sind umsetzbar, Beziehungen lassen sich inkrementell ändern, und die MCP-Oberfläche bleibt klein ([[derived.mcp.tools.total]] Tools, standardmäßig alle aktiv), damit auch kleinere Modelle sie zuverlässig bedienen können.
