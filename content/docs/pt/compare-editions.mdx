O Customermates funciona de duas maneiras: como Cloud, gerenciado pelo Customermates, e como Community Edition, que você hospeda com Docker Compose. O que nenhuma das duas edições inclui, como o login único e o white label, é combinado à parte em um acordo Enterprise. A página [Licença](/docs/licence) explica as licenças, e a [página de preços](/pricing) é a fonte de verdade para planos e preços. Esta página pode ficar atrás de uma versão.

## Quais recursos cada edição tem? [#which-features-does-each-edition-have]

| Recurso | Community Edition (auto-hospedada) | Cloud |
|---|---|---|
| Quem opera | Você: Docker, PostgreSQL, TLS, atualizações e backups | Customermates |
| Listas, registros, visualizações, modelo de dados e painéis | Sim | Sim |
| Membros, funções e permissões | Sim | Sim |
| Vários espaços de trabalho por login | Sim, sem cobrança | Sim, cada um com seu plano |
| Importação e exportação de Excel | Sim | Sim |
| Registro de atividades | Sim | Sim |
| API REST, webhooks, MCP com o seu próprio cliente de IA e n8n | Sim | Sim, os limites dependem do plano |
| Formulários públicos | Sim | Sim, os limites dependem do plano |
| Automações | Sim | Sim, os limites dependem do plano |
| Etapa de agente nas automações com a sua própria chave de IA | Sim | Nos planos pagos |
| Etapa de agente no seu próprio runner | Sim | Sim |
| Notificações e e-mails de resumo | Sim | Sim |
| Webhooks de entrada | Sim | Sim |
| Mensagens unificadas em todos os canais | Não | A partir do plano Pro |
| Sincronização de calendários | Não | A partir do plano Pro |
| Agendamento de reuniões e páginas de agendamento | Não | A partir do plano Pro |

## O que a Community Edition não inclui? [#what-does-the-community-edition-not-include]

Uma instância auto-hospedada tem o conjunto de recursos do Starter. Os recursos exclusivos do Cloud permanecem desativados, mesmo que você também pague um plano Cloud. O app oculta o que não se aplica: a barra lateral não mostra Caixa de entrada nem Rotinas, e as Configurações não têm a página Cobrança. [Auto-hospedagem](/docs/self-hosting#which-features-are-not-available-when-self-hosting) as lista por completo.

## O que exige um acordo Enterprise? [#what-needs-an-enterprise-agreement]

Estes itens exigem um acordo escrito sob a Customermates Enterprise License. Nenhum deles faz parte de um plano.

| O quê | Situação |
|---|---|
| Login único | Não integrado. Disponível como trabalho contratado. |
| White label | Mediante acordo. A marca do Customermates continua visível. |
| Incorporar o Customermates ao seu próprio produto | Mediante acordo. |
| Recursos Enterprise em uma instância auto-hospedada | Mediante acordo. Um plano Cloud não os desbloqueia. |
| Fluxos contratados de agentes sob medida e de dados de leads | Não integrados. Disponíveis como trabalho contratado. |

## Como passo de uma edição para outra? [#how-do-i-move-between-editions]

Os registros passam entre o Cloud e a auto-hospedagem como pastas de trabalho do Excel, uma lista por vez. Migrar a plataforma inteira é um projeto planejado à parte. Para um acordo Enterprise, use a [página de contato](/contact).
