Customermates est un CRM open source avec un point d’accès MCP natif. Claude, ChatGPT, Cursor et tout autre client qui parle le Model Context Protocol lisent et écrivent directement dans votre CRM, sans copier-coller.

## Ce qu’est Customermates [#what-customermates-is]

Un CRM avec des listes, des champs, des relations et des calculs configurables, des vues en tableau et en board, et des tableaux de bord. Sur Customermates Cloud, une configuration IA conçoit vos listes, votre pipeline, votre tableau de bord et votre base de connaissances à partir de quelques questions sur votre activité ; vous pouvez tout modifier et ajouter vos propres listes. Et aussi :

- **Point d’accès MCP natif** sur `/api/v1/mcp` : un client MCP découvre et appelle les opérations du CRM sans module d’extension.
- **Open source** sous AGPLv3 ; les composants entreprise relèvent d’une licence commerciale distincte. Auto-hébergez ou utilisez le cloud géré.
- **Cloud géré** avec sa base de données dans la région AWS de Francfort, un [DPA](/dpa), et chaque sous-traitant, fournisseurs américains compris, listé sur la [page des sous-traitants](/subprocessors).
- **Webhooks** avec des charges utiles signées en option, des nouvelles tentatives et un journal des envois.
- **Spécification OpenAPI 3.1** de toute l’interface REST sur `/api/v1/openapi`.
- **Mate**, l’assistant IA intégré à l’application sur Customermates Cloud : pas de client IA externe ni de configuration, il utilise les crédits inclus dans votre formule. Voir [Assistant](/docs/app-assistant).
- **Routines** qui exécutent Mate selon un calendrier ou lorsqu’un enregistrement change, sur Customermates Cloud. Voir [Routines](/docs/app-routines).
- **Boîte de réception** pour l’e-mail et les comptes LinkedIn, WhatsApp, Instagram et Telegram connectés, sur Customermates Cloud. Voir [Boîte de réception](/docs/app-inbox).
- **Rôles** qui décident, liste par liste, qui peut lire tous les enregistrements, seulement ceux qui lui sont assignés ou aucun, et qui peut les créer, les modifier ou les supprimer. Voir [Entreprise](/docs/app-company).

## Quatre façons dont Customermates se connecte à votre stack [#four-ways-customermates-connects-to-your-stack]

| Je veux | Utiliser |
| --- | --- |
| Qu’un client MCP mette à jour le CRM au fil d’une conversation | [MCP](/docs/mcp) |
| Construire une intégration sur mesure en code | [OpenAPI](/docs/openapi) |
| Réagir aux changements du CRM dans Slack, un outil de séquences, la BI ou votre entrepôt de données | [Webhooks](/docs/webhooks) |
| Composer des workflows visuellement sans code | [n8n](/docs/n8n) |

MCP, OpenAPI et n8n s’authentifient avec une clé d’API ; les clients MCP comme Claude et ChatGPT peuvent aussi se connecter en OAuth sans clé. Voir [Clés API](/docs/api-keys). Les webhooks fonctionnent dans l’autre sens : Customermates envoie chaque livraison à votre URL et, si le webhook a un secret, la signe, de sorte que votre récepteur vérifie cette signature ou un en-tête personnalisé que vous définissez sur le webhook.

## Approche de conception [#design-approach]

Customermates traite le client IA comme un utilisateur à part entière. Les outils portent des noms à l’impératif, les erreurs disent quoi faire, les relations changent de façon incrémentale, et la surface MCP reste petite (un seul point d’accès, tous les outils activés par défaut) pour que les petits modèles s’y repèrent de façon fiable.
