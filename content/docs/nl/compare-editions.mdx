Customermates draait op twee manieren: als Cloud, beheerd door Customermates, en als Community Edition, die je zelf host met Docker Compose. Wat geen van beide edities bevat, zoals single sign-on en white label, spreek je apart af in een Enterprise-overeenkomst. De pagina [Licentie](/docs/licence) legt de licenties uit, en de [prijzenpagina](/pricing) is leidend voor abonnementen en prijzen. Deze pagina kan een release achterlopen.

## Welke functies heeft elke editie? [#which-features-does-each-edition-have]

| Functie | Community Edition (zelf gehost) | Cloud |
|---|---|---|
| Wie het beheert | Jij: Docker, PostgreSQL, TLS, updates en back-ups | Customermates |
| Lijsten, records, weergaven, datamodel en dashboards | Ja | Ja |
| Leden, rollen en rechten | Ja | Ja |
| Meerdere workspaces per login | Ja, zonder facturering | Ja, elk met een eigen abonnement |
| Excel-import en -export | Ja | Ja |
| Activiteitenlogboek | Ja | Ja |
| REST API, webhooks, MCP met je eigen AI-client en n8n | Ja | Ja, limieten hangen af van het abonnement |
| Openbare formulieren | Ja | Ja, limieten hangen af van het abonnement |
| Automatiseringen | Ja | Ja, limieten hangen af van het abonnement |
| Agentstap in automatiseringen op je eigen AI-sleutel | Ja | Met een betaald abonnement |
| Agentstap op je eigen runner | Ja | Ja |
| Meldingen en samenvattingsmails | Ja | Ja |
| Inkomende webhooks | Ja | Ja |
| Gecombineerde berichten over alle kanalen | Nee | Vanaf het Pro-abonnement |
| Agendasynchronisatie | Nee | Vanaf het Pro-abonnement |
| Afspraken plannen en boekingspagina's | Nee | Vanaf het Pro-abonnement |
| Mate, de gehoste assistent, met gehoste AI-credits | Nee | Ja, gebruik hangt af van het abonnement |
| Routines die Mate uitvoert | Nee | Ja |
| AI-inrichting van de workspace bij onboarding | Nee | Ja |
| Hele accounts delen | Nee | Vanaf het Business-abonnement |
| Licentie | Sustainable Use License, gratis voor je eigen bedrijf | Een abonnement met eigen voorwaarden |

## Wat bevat de Community Edition niet? [#what-does-the-community-edition-not-include]

Een zelf gehoste instantie heeft de functies van Starter. De functies die alleen Cloud biedt, blijven uit, ook als je daarnaast een Cloud-abonnement betaalt. De app verbergt wat niet van toepassing is: de zijbalk toont geen Inbox of Routines, en Instellingen heeft geen pagina Facturering. [Zelf hosten](/docs/self-hosting#which-features-are-not-available-when-self-hosting) somt ze volledig op.

## Wat vraagt een Enterprise-overeenkomst? [#what-needs-an-enterprise-agreement]

Hiervoor is een schriftelijke overeenkomst onder de Customermates Enterprise License nodig. Niets hiervan maakt deel uit van een abonnement.

| Wat | Stand |
|---|---|
| Single sign-on | Niet ingebouwd. Mogelijk als opdrachtwerk. |
| White label | Via overeenkomst. De Customermates-branding blijft zichtbaar. |
| Customermates in je eigen product insluiten | Via overeenkomst. |
| Enterprise-functies op een zelf gehoste instantie | Via overeenkomst. Een Cloud-abonnement ontgrendelt ze niet. |
| Opgedragen workflows voor eigen agents en leaddata | Niet ingebouwd. Mogelijk als opdrachtwerk. |

## Hoe stap ik over van de ene editie naar de andere? [#how-do-i-move-between-editions]

Records gaan als Excel-werkmappen tussen Cloud en zelf hosten, één lijst per keer. Een migratie van het hele platform is een apart ontworpen project. Voor een Enterprise-overeenkomst gebruik je de [contactpagina](/contact).
