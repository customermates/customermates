Customermates runs in two ways: as Cloud, managed by Customermates, and as the Community Edition, which you host yourself with Docker Compose. Work that neither edition includes, such as single sign-on and white-labelling, is agreed separately under an enterprise agreement. The [Licence](/docs/licence) page explains the licences, and the [pricing page](/pricing) is the source of truth for plans and prices. This page can lag behind a release.

## Which features does each edition have? [#which-features-does-each-edition-have]

| Feature | Community Edition (self-hosted) | Cloud |
|---|---|---|
| Who runs it | You: Docker, PostgreSQL, TLS, updates and backups | Customermates |
| Lists, records, views, data model and dashboards | Yes | Yes |
| Members, roles and permissions | Yes | Yes |
| Several workspaces per login | Yes, without billing | Yes, each with its own plan |
| Excel import and export | Yes | Yes |
| Activity log | Yes | Yes |
| REST API, webhooks, MCP with your own AI client and n8n | Yes | Yes, limits depend on the plan |
| Public forms | Yes | Yes, limits depend on the plan |
| Automations | Yes | Yes, limits depend on the plan |
| Notifications and email digests | Yes | Yes |
| Incoming webhooks | Yes | Yes |
| Unified inbox for email, LinkedIn, WhatsApp, Instagram and Telegram | No | From the Pro plan |
| Connected calendars | No | From the Pro plan |
| Scheduling meetings and booking pages | No | From the Pro plan |
| Mate, the hosted assistant, with hosted AI credits | No | Yes, usage depends on the plan |
| Routines that Mate runs | No | Yes |
| AI workspace setup in onboarding | No | Yes |
| Whole-account sharing | No | From the Business plan |
| Licence | Sustainable Use License, free for your own business | A subscription with its own terms |

## What does the Community Edition not include? [#what-does-the-community-edition-not-include]

A self-hosted instance has the Starter feature set. The cloud-only features stay off, even if you also pay for a Cloud plan. The app hides what does not apply: the sidebar shows no Inbox or Routines, and Settings has no Billing page. [Self-hosting](/docs/self-hosting#which-features-are-not-available-when-self-hosting) lists them in full.

## What needs an enterprise agreement? [#what-needs-an-enterprise-agreement]

These need a written agreement under the Customermates Enterprise License. None of them is part of a plan.

| What | Status |
|---|---|
| Single sign-on | Not built in. Available as contracted work. |
| White-label | By agreement. The Customermates branding stays visible. |
| Embedding Customermates in your own product | By agreement. |
| Enterprise Features on a self-hosted instance | By agreement. A Cloud plan does not unlock them. |
| Contracted custom-agent and lead-data workflows | Not built in. Available as contracted work. |

## How do I move between editions? [#how-do-i-move-between-editions]

Records move between Cloud and self-hosted as Excel workbooks, one list at a time. A migration of a whole platform is a separately designed project. For an enterprise agreement, use the [contact page](/contact).
