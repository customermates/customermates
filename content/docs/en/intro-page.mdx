Customermates is an open-source CRM with a native MCP endpoint. Claude, ChatGPT, Cursor and any other client that speaks the Model Context Protocol read and write your CRM directly, without copy-paste.

## What Customermates is [#what-customermates-is]

A CRM with configurable lists, fields, relationships and calculations, table and board views, and dashboards. It starts with Contacts, Organizations, Deals, Services and Tasks, and you can add your own lists. Plus:

- **Native MCP endpoint** at `/api/v1/mcp`: an MCP client discovers and calls CRM operations without a plugin.
- **Open source** under AGPLv3; enterprise components are under a separate commercial license. Self-host or use the managed cloud.
- **Managed cloud** with its database in the AWS Frankfurt region, a [DPA](/dpa), and every subprocessor, including US providers, listed on the [subprocessors page](/subprocessors).
- **Webhooks** with optionally signed payloads, retries and a delivery log.
- **OpenAPI 3.1** specification for the full REST surface at `/api/v1/openapi`.
- **Mate**, the in-app AI assistant on Customermates Cloud: no external AI client or setup, it uses the credits included in your plan. See [Assistant](/docs/app-assistant).
- **Routines** that run Mate on a schedule or when a record changes, on Customermates Cloud. See [Routines](/docs/app-routines).
- **Inbox** for email and connected LinkedIn, WhatsApp, Instagram and Telegram accounts, on Customermates Cloud. See [Inbox](/docs/app-inbox).
- **Roles** that decide per list who can read all records, only assigned ones or none, and who can create, edit or delete them. See [Company](/docs/app-company).

## Four ways Customermates connects to your stack [#four-ways-customermates-connects-to-your-stack]

| I want to | Use |
| --- | --- |
| Have an MCP client update the CRM in conversation | [MCP](/docs/mcp) |
| Build a custom integration in code | [OpenAPI](/docs/openapi) |
| React to CRM changes in Slack, a sequencer, BI, or your warehouse | [Webhooks](/docs/webhooks) |
| Compose workflows visually without code | [n8n](/docs/n8n) |

MCP, OpenAPI and n8n authenticate with an API key; MCP clients such as Claude and ChatGPT can also connect over OAuth without one. See [API keys](/docs/api-keys). Webhooks work the other way round: Customermates sends each delivery to your URL and, if the webhook has a secret, signs it, so your receiver checks that signature or a custom header you set on the webhook.

## Design approach [#design-approach]

Customermates treats the AI client as a first-class user. Tools are named imperatively, errors say what to do, relationships change incrementally, and the MCP surface stays small ([[derived.mcp.tools.total]] tools, all on by default) so smaller models navigate it reliably.
