    title: Comment fonctionne le suivi ?
    content: Customermates utilise le script de suivi d’affiliation standard de Lemon Squeezy sur les pages de contenu public du cloud géré, afin d’attribuer les visites et les achats recommandés et de répartir la commission. Une visite sur l’une de ces pages demande le script à `lmsqueezy.com`, immédiatement lorsque l’URL contient un code d’affiliation, et sinon une fois la page chargée et le navigateur inactif ou dès la première interaction du visiteur avec la page, ce qui peut divulguer des données de requête réseau ordinaires même sans code d’affiliation. Lorsqu’un visiteur arrive par un lien d’affiliation, le script lit le code `aff`, envoie à Lemon Squeezy l’URL de destination, le référent, la référence de recommandation et un identifiant de visiteur dérivé du navigateur, et enregistre le cookie de recommandation `ls_aff_ref` pour la période de suivi configurée dans Lemon Squeezy. Il peut ajouter la référence de recommandation aux liens de paiement Lemon Squeezy de ces pages. Le script n’est pas soumis à un mécanisme de consentement distinct de Customermates. Les routes authentifiées, d’authentification, d’invitation, de démonstration et les routes auto-hébergées en amont ne le chargent pas. Le lien d’inscription au programme d’affiliation ouvre le site hébergé de Lemon Squeezy, où s’applique la politique de confidentialité de Lemon Squeezy. Consultez la politique de confidentialité de Customermates pour la base juridique et l’information sur l’accès à l’appareil.
