  - id: faq-7
    title: ¿Cómo funciona el seguimiento?
    content: Customermates usa el script de seguimiento de afiliados estándar de Lemon Squeezy en las páginas de contenido público de la nube gestionada para atribuir las visitas y compras referidas y asignar la comisión. Al visitar una de esas páginas, se solicita el script a `lmsqueezy.com`, de inmediato si la URL lleva un código de afiliado y, si no, cuando la página ya se ha cargado y el navegador está inactivo o el visitante interactúa con ella por primera vez, lo que puede revelar datos habituales de las solicitudes de red incluso sin código de afiliado. Cuando un visitante llega a través de un enlace de afiliado, el script lee el código `aff`, envía a Lemon Squeezy la URL de llegada, el referente, la referencia del referido y un identificador del visitante derivado del navegador, y guarda la cookie de referido `ls_aff_ref` durante el periodo de seguimiento configurado en Lemon Squeezy. Puede añadir la referencia del referido a los enlaces de pago de Lemon Squeezy de esas páginas. El script no depende de un mecanismo de consentimiento propio de Customermates. Las rutas autenticadas, de autenticación, de invitación, de demostración y las rutas autoalojadas del proyecto original no lo cargan. El enlace de registro de afiliados abre el sitio web alojado de Lemon Squeezy, donde se aplica la política de privacidad de Lemon Squeezy.
