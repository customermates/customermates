# Salesforce MCP spiegato: quale server fa cosa e quanto costa

Sì, Salesforce ha propri server MCP, e quando si parla di «Salesforce MCP» di solito si intendono i **Salesforce Hosted MCP Servers**: endpoint gestiti da Salesforce che permettono a Claude, ChatGPT, Cursor o a un altro client MCP di leggere e modificare i record della tua org con i permessi di ciascun utente. Sono disponibili in via generale dal 29 aprile 2026 per le org Enterprise Edition e superiori. Un amministratore deve attivarli e Salesforce dice che sono destinati ai clienti con Flex Credits.

Gli sviluppatori di solito intendono altro: il server MCP open source Salesforce DX, che gira sul loro computer come [server MCP locale](/blog/what-is-an-mcp-server). Anche MuleSoft e Heroku hanno offerte MCP proprie. Questa guida distingue le quattro, mostra la configurazione e le regole di fatturazione come Salesforce le documenta all’8 ottobre 2026 e confronta l’approccio con un CRM il cui server MCP è incluso nel prodotto. Trasparenza: Customermates, il secondo CRM di cui si parla qui, pubblica questa guida.

## Le quattro offerte MCP di Salesforce

| Offerta | Per chi è | Dove gira | Cosa fa |
| --- | --- | --- | --- |
| Hosted MCP Servers | Team di vendita, assistenza e IA, configurati dagli admin | Ospitato da Salesforce | Leggere, creare, aggiornare ed eliminare record; interrogare e cercare; strumenti personalizzati da Apex, Flow e query con nome |
| Server MCP Salesforce DX | Sviluppatori Salesforce | In locale, tramite `npx` | Gestione delle org, metadati, dati, test Apex, analisi del codice, Lightning Web Components |
| MuleSoft MCP Connector | Team di integrazione | Dentro le app Mule | Trasforma le app Mule in server o client MCP, così le API esistenti raggiungono gli agenti IA |
| Server MCP Heroku | Sviluppatori Heroku | In locale o distribuito su Heroku | Gestisce app Heroku, dyno, add-on, database e pipeline |

Se lavori nelle vendite o nell’assistenza e vuoi che il tuo assistente IA veda account e opportunità, ti interessa solo la prima riga.

## Salesforce Hosted MCP Servers

Un server MCP ospitato è un endpoint che Salesforce gestisce davanti alla tua org. Non installi nulla. Ogni persona collega il proprio client IA, accede con OAuth e ogni chiamata a uno strumento viene eseguita come quella persona: valgono i permessi sugli oggetti, la sicurezza a livello di campo e le regole di condivisione, e un record modificato dall’agente mostra il nome di quell’utente nel registro di audit.

**Server standard.** Salesforce fornisce server preconfigurati con insiemi di strumenti fissi. Sono disattivati per impostazione predefinita e un admin può abilitarli ma non cambiarne gli strumenti. Il [riferimento dei server standard](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/servers-reference.html) elenca questi:

| Server | Ambito |
| --- | --- |
| SObject All | Creare, leggere, aggiornare, eliminare, interrogare e cercare tra gli oggetti |
| SObject Reads | Solo lettura e interrogazione |
| SObject Mutations | Creare e aggiornare, senza eliminare |
| SObject Deletes | Solo eliminazione |
| Data 360 | Query SQL sui dati unificati dei clienti |
| Tableau Next | Modelli semantici, KPI e domande di analisi |
| Backup and Recover | Backup, policy di backup e ripristino guidato |
| Content Read-Only, Content Write | Spazi di lavoro, canali e contenuti di Salesforce CMS |
| Headless 360 (Beta) | Setup e funzionalità della piattaforma, compresi gli strumenti Archive Connect |
| CRM Analytics (Beta) | Metadati di analisi in sola lettura e SAQL; solo sandbox e scratch org |

I server SObject separati sono il controllo pratico. Un gruppo pilota può ricevere prima SObject Reads, e l’accesso in scrittura o di eliminazione dopo, per server e non per prompt.

**Server personalizzati.** Oltre all’insieme standard, gli admin possono [creare server personalizzati](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/products-supporting-mcp.html) i cui strumenti sono azioni invocabili Apex, metodi `@AuraEnabled`, metodi Apex REST, Flow, query con nome ed endpoint dell’API Catalog. I template di Prompt Builder possono comparire come prompt MCP, anche se non tutti i client supportano i prompt MCP. È qui che un’org Salesforce con anni di logica personalizzata ricava di più da MCP: un Flow convalidato «crea opportunità di rinnovo» diventa uno strumento invece di cinque scritture grezze di record.

**Cambiamenti nel tempo.** Salesforce afferma nel suo [avviso di fine vita](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/end-of-life.html) che strumenti, prompt e risorse possono cambiare da una release all’altra e che i server possono essere ritirati con preavviso. Basa le tue aspettative sul riferimento dei server, non su un articolo di blog del trimestre scorso.

## Salesforce MCP è gratuito?

Non in un modo su cui contare. La [panoramica dei server MCP ospitati](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/hosted-mcp-servers-overview.html) dice che i server sono «destinati solo ai clienti con Flex Credits» e che «l’utilizzo del server potrebbe esserti fatturato».

Un articolo di Salesforce Help del 17 settembre 2026, [Understand AIforce Impact](https://help.salesforce.com/s/articleView?language=en_US&id=005360285&type=1), descrive dove si sta andando:

- Salesforce punta a novembre per la registrazione degli agenti e un nuovo modello di fatturazione. Ogni agente esterno ottiene la propria identità e può avere un insieme di permessi più ristretto della persona per cui lavora.
- Ogni chiamata riuscita di un agente registrato, via MCP o tramite l’API diretta, viene misurata come Headless Platform Interaction (HPI) rispetto ai Flex Credits.
- Il moltiplicatore HPI è indicato come «TBA», e l’uso agentico non viene ancora misurato. Salesforce promette 30 giorni di preavviso prima dell’inizio della misurazione.
- L’uso di qualsiasi server MCP di Salesforce richiederà la registrazione dell’agente entro tre mesi dall’avviso di Salesforce, per tutti i clienti. I clienti esistenti che usano agenti con le API di Salesforce migrano queste connessioni al nuovo modello di fatturazione al rinnovo.
- Sandbox, scratch org e org Developer Edition non comportano la misurazione HPI.
- Un’org deve avere attiva la fatturazione a Flex Credit, per esempio tramite Salesforce Foundations, che l’articolo indica come attualmente disponibile a 0 $ (verificato l’8 ottobre 2026).

Quindi la risposta onesta sul costo è: la misurazione HPI non è ancora attiva, Salesforce si riserva già il diritto di fatturare l’uso dei server e l’entità dell’addebito a chiamata annunciato è sconosciuta. Se pianifichi un’introduzione per un intero team di vendita, chiedi il tasso HPI al tuo account executive prima di fare il budget e svolgi il pilota in una sandbox, dove le chiamate non vengono misurate.

## Come attivare Salesforce MCP

L’annuncio della disponibilità generale di Salesforce indica il percorso più breve in meno di 30 minuti. I passi qui sotto seguono la [panoramica della configurazione](https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/setup-overview.html) e l’[annuncio della disponibilità generale](https://developer.salesforce.com/blogs/2026/04/salesforce-hosted-mcp-servers-are-now-generally-available).

<Steps>
  <Step title="Controlla edizione e permessi">
    Ti serve un’org Enterprise Edition o superiore e i diritti di System Administrator (o equivalenti) per creare una External Client App.
  </Step>
  <Step title="Abilita un server">
    In Setup vai su API Catalog, poi MCP Servers, e abilita un server. Parti da SObject Reads in una sandbox.
  </Step>
  <Step title="Crea una External Client App">
    Registra il client MCP con gli scope OAuth mcp_api e refresh_token, abilita PKCE e i token basati su JWT e inserisci l’URL di callback che il tuo client documenta. Lo scope mcp_api concede solo l’accesso MCP, non le API REST esistenti.
  </Step>
  <Step title="Collega il client">
    Aggiungi l’URL del server in Claude, ChatGPT, Cursor o Postman, accedi e fai una domanda di lettura su un account che conosci bene, così puoi verificare la risposta.
  </Step>
  <Step title="Amplia l’accesso con criterio">
    Aggiungi SObject Mutations o server personalizzati per un gruppo pilota con nomi precisi quando le letture si comportano come previsto. Tieni disattivato SObject Deletes finché qualcuno non ne ha bisogno.
  </Step>
</Steps>

## Il Salesforce DX MCP server

Il [server MCP Salesforce DX](https://github.com/salesforcecli/mcp) è open source con licenza Apache 2.0 e gira in locale con `npx @salesforce/mcp`. Raggiunge solo le org che hai già autorizzato sul tuo computer tramite la Salesforce CLI o VS Code, e l’argomento `--orgs` limita quali. I suoi set di strumenti coprono org, metadati, dati, utenti, test, analisi del codice, DevOps, Lightning Web Components, Aura e mobile, con più di 60 strumenti in totale. Gli strumenti non ancora in disponibilità generale richiedono il flag `--allow-non-ga-tools`.

Usalo quando un assistente di programmazione come Claude Code o Cursor deve distribuire metadati, eseguire test Apex o interrogare una scratch org. Non è il modo in cui un venditore dovrebbe raggiungere i dati CRM.

## MuleSoft e Heroku MCP

Il [MuleSoft MCP Connector](https://docs.mulesoft.com/mcp-connector/latest/) permette alle app Mule di agire come server MCP o client MCP. Conta quando un agente IA deve raggiungere un ERP o un sistema legacy che non ha un proprio server MCP, con MuleSoft nel mezzo. Heroku pubblica un [server MCP Apache 2.0](https://github.com/heroku/heroku-mcp-server) che gira tramite la Heroku CLI o `npx`, oppure può essere distribuito su Heroku, e gestisce app, dyno, add-on e pipeline. Nessuno dei due è uno strumento di vendita.

## Un CRM con un server MCP integrato

Se non ti sei ancora impegnato con Salesforce, esiste un modello diverso: un CRM il cui server MCP fa parte del prodotto. Customermates è uno di questi. È un CRM open source e nativo per l’IA per piccoli team a contatto con i clienti, ed espone un endpoint MCP a `/api/v1/mcp` su ogni piano cloud e sulle installazioni self-hosted. Un client collegato scopre [[derived.mcp.tools.total]] strumenti per contatti, organizzazioni, trattative, servizi, attività e i tuoi elenchi, il modello dati, le viste salvate, le dashboard, le routine e i webhook. Da Pro in su, in Customermates Cloud, si aggiungono gli strumenti della Posta in arrivo unificata per e-mail, LinkedIn, WhatsApp, Instagram e Telegram.

La connessione funziona in due modi, come descrive la [documentazione MCP](/docs/mcp). Claude e ChatGPT si collegano come connettore personalizzato: incolla l’URL, accedi, approva. Claude Code, Codex, Cursor e Gemini CLI usano una [chiave API](/docs/api-keys) che eredita i permessi di chi l’ha creata. Per esporre solo una parte degli strumenti, aggiungi `?toolsets=` all’URL dell’endpoint, per esempio `?toolsets=records`.

| Domanda | Salesforce Hosted MCP Servers | Customermates MCP |
| --- | --- | --- |
| Chi lo configura | System Administrator: attivazione del server ed External Client App | Ogni utente collega il proprio client; per creare chiavi API serve il relativo permesso di ruolo |
| Edizioni o piani | Enterprise Edition e superiori | Ogni piano cloud e self-hosted |
| Costo d’uso | Flex Credits; misurazione HPI a chiamata annunciata, tariffa TBA | Nessun addebito a chiamata; il tuo client IA usa il tuo fornitore di IA |
| Controllo dell’ambito | Server separati per lettura, scrittura ed eliminazione; sicurezza a livello di campo | Permessi di ruolo per risorsa e azione; restrizione dei toolset tramite URL; nessun permesso a livello di campo |
| Strumenti personalizzati | Apex, Flow, query con nome, API Catalog, template di prompt | Catalogo di strumenti fisso; si estende tramite REST e webhook |
| Licenza | Servizio proprietario; il server DX è Apache 2.0 | Core AGPL, installabile in self-hosting |

Il conto dei costi è semplice. Un team di cinque persone su Starter paga [[commercial.price.starter.monthly.seats.5]] al mese e ottiene tutto l’insieme di strumenti CRM via MCP. Gli strumenti della Posta in arrivo richiedono Pro, [[commercial.price.pro.monthly.seats.5]] al mese per lo stesso team. L’abbonamento del client IA si aggiunge, presso Anthropic, OpenAI o qualunque fornitore usi. I prezzi attuali sono nella [pagina dei prezzi](/pricing).

Una differenza di controllo conta. Il server MCP di Customermates indica ai client di ottenere la conferma dell’utente prima di eliminare o inviare, ma quella conferma avviene nel client. Quando un client autorizzato chiama uno strumento, il server lo esegue. Controlla come il tuo client gestisce le approvazioni e parti da letture e bozze.

Per un team a contatto con i clienti, il senso di MCP è il follow-up: con LinkedIn ed e-mail collegati su Customermates Cloud da Pro, il tuo Claude o ChatGPT legge la conversazione sul record del cliente e prepara la bozza di risposta e il passo successivo, che tu rivedi e invii. Per provarlo, [avvia la prova](/auth/signup?job=followup): [[commercial.trial.days]] giorni di Pro senza carta di credito.

**Dove Customermates è la scelta sbagliata.** Se usi già Salesforce con oggetti personalizzati, logica Apex, modelli di territorio o condivisione e sicurezza a livello di campo, resta su Salesforce e usa i server ospitati: il passaggio fa perdere più di quanto dia. Customermates inoltre non ha definizioni di strumenti personalizzati né permessi a livello di campo. Si adatta a una società di consulenza, a un’agenzia o a un team guidato dal founder che sceglie il suo primo vero CRM, o ne lascia uno grande. Il [confronto con le alternative a Salesforce](/compare/salesforce-alternative) tratta questa decisione e la [guida a HubSpot MCP](/blog/hubspot-mcp) tratta il server remoto di HubSpot.

## Domande frequenti

<Faq>
<FaqItem question="Che cos’è Salesforce MCP?">
È il supporto di Salesforce al Model Context Protocol, lo standard aperto che permette ai client IA di chiamare strumenti in altri sistemi. In pratica significa Salesforce Hosted MCP Servers per i dati CRM, il server MCP locale Salesforce DX per gli sviluppatori e le offerte MCP per MuleSoft e Heroku.
</FaqItem>

<FaqItem question="Salesforce ha un proprio server MCP?">
Sì. Salesforce gestisce direttamente gli Hosted MCP Servers, disponibili in via generale dal 29 aprile 2026, e pubblica su GitHub il server MCP open source DX. Esistono anche server MCP Salesforce di terze parti, ma non ne hai bisogno per collegare Claude o ChatGPT a Salesforce.
</FaqItem>

<FaqItem question="Salesforce MCP è gratuito?">
Il server MCP DX è software open source gratuito. I server ospitati sono destinati ai clienti con Flex Credits e Salesforce ha annunciato una misurazione a chiamata per gli agenti registrati. All’8 ottobre 2026 la tariffa è indicata come TBA e non ancora misurata, e sandbox, scratch org e org Developer Edition sono esentate da quella misurazione.
</FaqItem>

<FaqItem question="Come si attiva Salesforce MCP?">
Un System Administrator abilita un server in Setup sotto API Catalog, poi MCP Servers, crea una External Client App con gli scope mcp_api e refresh_token e PKCE e aggiunge l’URL di callback del client. Gli utenti collegano poi il proprio client IA e accedono con OAuth.
</FaqItem>

<FaqItem question="Quali edizioni di Salesforce supportano i server MCP ospitati?">
Salesforce li descrive come disponibili per ogni org Enterprise Edition e superiore. Alcuni singoli server, come Headless 360 e CRM Analytics, sono ancora indicati come beta.
</FaqItem>

<FaqItem question="Salesforce MCP rispetta i permessi degli utenti?">
Sì. Ogni chiamata viene eseguita come l’utente connesso, quindi valgono i permessi sugli oggetti, la sicurezza a livello di campo e le regole di condivisione. Se un utente non può fare qualcosa in Salesforce, nemmeno l’agente può farlo per lui.
</FaqItem>
</Faq>
