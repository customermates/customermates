# Agentforce Explained: Agents, Credits, Einstein and Setup

Salesforce Agentforce is Salesforce's platform for AI agents that work on the data in your Salesforce org. Customer-facing agents answer on your website, in messaging channels and on the phone. Employee agents work inside Salesforce, for example by updating a record or summarizing a case. You pay per agent action with Flex Credits, per customer conversation, or per user through add-ons and the Max editions.

Agentforce does not run on its own. It needs a Salesforce org, and the free way in is Salesforce Foundations, a $0 add-on for Enterprise Edition and higher. Einstein, the older brand, now mostly names the layer underneath: the Einstein Trust Layer masks data and scores responses for toxicity, while the assistant once called Einstein Copilot is part of Agentforce.

Customermates, an open-source CRM, publishes this guide. Salesforce facts come from Salesforce's own pages, checked on 8 October 2026 and linked at the end. Customermates appears once, in its own labelled section.

## How an Agentforce agent works

An agent is a role, a set of topics, written instructions and the actions it may take, all configured in Agentforce Builder. When a request arrives, the Atlas Reasoning Engine works out what the person wants and which action to run next. Salesforce calls this hybrid reasoning, combining "deterministic logic and adaptive AI": Agent Script holds the steps that must run the same way every time, and the model handles the rest.

| Building block | What it does |
|---|---|
| Agentforce Builder | Where you define an agent's role, topics, instructions and permitted actions |
| Agent Script | Fixed logic for the parts of a conversation that must not vary |
| Atlas Reasoning Engine | Interprets the request and chooses the next action |
| Actions | One function an agent executes, such as updating a record, summarizing a case or answering a product question. Flex Credits are billed per action |
| Agentforce Data Library | Indexes Knowledge articles, uploaded text, HTML and PDF files, and web search results, so answers rest on your content |
| Data 360 (formerly Data Cloud) | Salesforce's data platform, which unifies data from other systems into one customer profile |
| Einstein Trust Layer | Masks sensitive data, checks responses for toxicity and keeps an audit trail |
| Model Builder | Lets you bring your own language model, for example from Anthropic, Google, OpenAI or Hugging Face |

Salesforce lists the web, the phone, apps, self-service portals and messaging channels as places to deploy agents, and MuleSoft API connectors for reaching systems outside Salesforce.

### One question, followed through

A customer types into your web chat: "Where is my order 4711?" The agent matches the topic "Order status", and the reasoning engine calls three actions: one finds the customer, one looks up the order, one reads the shipping status. Before the prompt goes to the language model, the Trust Layer can swap the customer's name and email address for placeholders. When the answer comes back, it is checked for toxicity, the real values are put back in, and the exchange is written to the audit trail.

Billed in Flex Credits, those three standard actions use 60 credits, which is $0.30. Billed per conversation, the same exchange costs $2. That gap is the main pricing decision: per-conversation pricing only comes out cheaper once an average conversation runs more than 20 standard actions.

## The Einstein Trust Layer and its toxicity score

The Trust Layer sits between Salesforce and the language model. Salesforce lists secure data retrieval and grounding, data masking, zero data retention (prompts and responses are never stored or used to train the underlying third-party models), toxicity detection and security guardrails.

The toxicity score is what most people look for in the documentation. Salesforce's Trailhead module on the response journey explains that the overall score runs from 0 to 1, where 1 is the most toxic, and that it covers five categories: violence, sexual, profanity, hate and physical. The audit trail stores the prompt, the original unfiltered response, any toxicity scores and the feedback collected along the way. Review it after a pilot, before you let an agent answer customers unsupervised.

## What Agentforce costs

These are Salesforce's list prices from the [Agentforce pricing page](https://www.salesforce.com/agentforce/pricing/), checked on 8 October 2026.

| Option | List price | What you get |
|---|---|---|
| Salesforce Foundations | $0 add-on | Agentforce Builder, Prompt Builder, Agent Script, Agentforce Coworker, Agentforce Vibes and a starting allowance of Flex Credits. For Enterprise Edition and higher; availability varies by edition and region |
| Flex Credits | $500 per 100,000 credits | 20 credits ($0.10) per standard action, 30 credits ($0.15) per voice action |
| Conversations | $2 per conversation | Customer-facing agents only. Flex Credits and Conversations are not supported in the same org |
| Agentforce User License | $5 per user per month, plus Flex Credits | Agentforce access for every employee, limited CRM objects, metered usage |
| Agentforce add-ons for Sales, Service, Field Service | $125 per user per month | Unmetered Agentforce use for employees, plus Prompt Builder and AI analytics |
| Max editions | from $550 per user per month | The add-on included, plus 2.75 million Flex Credits per org per year |

The [Foundations page](https://www.salesforce.com/crm/foundations/) currently lists 450,000 Flex Credits for Agentforce and Data 360 "to get started (restrictions apply)". Older Salesforce pages give smaller numbers, so confirm the figure for your org.

You buy usage up front for the contract term (Pre-Purchase), commit to a baseline with no upfront payment (Pre-Commit, which Salesforce says becomes widely available later this year), or pay only for what you use with no commitment (PayGo).

All of this sits on top of a Salesforce edition. On the [Sales pricing page](https://www.salesforce.com/sales/pricing/), Starter Suite costs $25, Pro Suite $100, Core $195, Advanced $395 and Max $550 per user per month. Starter Suite can be billed monthly or annually; the other four are billed annually.

### A 10-person sales team, worked through

| Setup | Per month | Per year |
|---|---:|---:|
| Core plus the Agentforce for Sales add-on: 10 × $195 + 10 × $125 | $3,200 | $38,400 |
| Max, which includes Agentforce for Sales and Agentforce Coworker: 10 × $550 | $5,500 | $66,000 |
| A service agent with 2,000 customer conversations a month, priced per conversation | $4,000 | $48,000 |
| The same 2,000 conversations on Flex Credits, at an average of three standard actions | $600 | $7,200 |

The last two rows are alternatives, because one org uses Flex Credits or Conversations, not both. None of these figures includes Data 360 usage beyond the included credits (Salesforce notes that overage fees apply), implementation work or any discount in your contract. Every Salesforce edition and add-on is listed in the [Salesforce pricing guide](/blog/salesforce-pricing).

Looking for an Einstein GPT price? Salesforce's current pricing pages list no product under that name. Generative features such as Prompt Builder come with Foundations, the add-ons and the Max editions, and agent actions are paid in Flex Credits.

## Agentforce, Einstein and the other new names

Salesforce has renamed several products in a short time, which is why search results contradict each other.

| Name you may see | What it is now |
|---|---|
| Einstein | The older name for AI across Salesforce. It lives on in the Einstein Trust Layer |
| Einstein Copilot | The conversational assistant. It became Agentforce Assistant and was then upgraded to Agentforce |
| Einstein GPT | No separate product on today's pricing pages |
| Data Cloud | Renamed Data 360 |
| Service Cloud | Salesforce's help documentation now calls it Agentforce Service |
| Agentforce 360 Platform | The name of the platform the agents run on |

## Introducing Agentforce, one use case at a time

<Steps>
  <Step title="Check your edition">The sales pricing page says AI can be added to Core and above, while its comparison table marks some Agentforce features as available for purchase on Starter Suite and Pro Suite. Foundations is for Enterprise Edition and higher, and Salesforce says its availability varies by region, so ask your account executive what your org gets.</Step>
  <Step title="Pick one use case with a number attached">For example, order-status questions in web chat, or an opportunity summary before a sales call. Write down today's figure, such as weekly tickets on that topic, so the pilot has something to beat.</Step>
  <Step title="Clean what the agent will read">The Data Library grounds answers in your Knowledge articles, files and web sources. An outdated article becomes an outdated answer.</Step>
  <Step title="Build the agent in Agentforce Builder">Define the topic, the instructions and the actions. Put anything that must always happen the same way, such as checking who the customer is before showing order data, into Agent Script.</Step>
  <Step title="Test with real past questions">Run a batch of genuine customer or seller questions through the agent, then read the audit trail and the toxicity scores. Rewrite instructions where answers drift.</Step>
  <Step title="Choose the pricing model before go-live">Flex Credits or Conversations, not both in one org. Apply the 20-action break-even to your own volumes. PayGo suits a pilot; Pre-Purchase makes sense once volume is known.</Step>
  <Step title="Go live on one channel">Start with one channel and one topic, decide what happens when the agent cannot answer, and review the audit trail weekly before adding the next topic.</Step>
</Steps>

Without a Salesforce admin in-house, budget for a Salesforce consulting partner. The general rollout questions, from data cleanup to training, are in the [CRM implementation guide](/blog/crm-implementation).

## When Agentforce fits, and when to look elsewhere

| Your situation | Better fit |
|---|---|
| Your company runs on Salesforce and keeps Knowledge articles current | Agentforce. The agents work on records and content you already maintain |
| You need a service agent on web chat, messaging or the phone around the clock | Agentforce Service, priced per conversation or in Flex Credits |
| You are on Starter Suite or Pro Suite and want to try agents | Ask Salesforce which Agentforce features your edition can buy; Foundations needs Enterprise Edition or higher |
| You want Claude or ChatGPT to work on your Salesforce data from your own AI client | An MCP connection, covered in the [Salesforce MCP guide](/blog/salesforce-mcp) |
| You have no CRM yet, or a small team with nobody to run Salesforce | A smaller CRM whose AI is part of the plan; the [agentic CRM guide](/blog/agentic-crm) explains what to look for |

## Where Customermates fits

A routine for a consultancy might run **On a schedule**, **Every day** at 08:00, with these instructions:

```text
Look at the open deals assigned to me. For each deal, read the
latest conversation with its contacts. If the client wrote last
and has no reply yet, save a reply draft in that thread, in the
language of the conversation. Do not send anything.
End with a list of the drafts you saved.
```

A routine runs as its owner, with the owner's connected channels and permissions, and refuses anything that would need approval. Mate sends messages when asked to, which is why the instruction says "Do not send anything".

For the same 10 people, Pro costs [[commercial.price.pro.monthly.seats.10]] per month. That includes the [unified inbox](/features/unified-inbox) with [[commercial.entitlement.pro.includedAccountsPerUser]] connected account per user (email, LinkedIn, WhatsApp, Instagram or Telegram), up to [[commercial.entitlement.pro.includedRoutinesPerUser]] routines per user and monthly hosted AI credits per active user. ## Frequently asked questions

<Faq>
<FaqItem question="Is Agentforce free on Salesforce?">
Partly. Salesforce Foundations is a $0 add-on for orgs on Enterprise Edition and higher, with Agentforce Builder, Prompt Builder, Agent Script and a starting allowance of Flex Credits, under limits and terms. After that, actions cost $0.10 each in Flex Credits, or you switch to per-conversation pricing or a per-user add-on.
</FaqItem>

<FaqItem question="Has Salesforce been renamed to Agentforce?">
No. The company is still Salesforce, and its sales pricing page still compares Sales Cloud editions. Agentforce is the name of the agent platform, and Salesforce has started using it in other product names, such as Agentforce Service.
</FaqItem>

<FaqItem question="What is the difference between Agentforce and Salesforce Einstein?">
Einstein is the older name for AI across Salesforce. Agentforce is the platform for agents that act on their own. Einstein Copilot became part of Agentforce, and the Einstein Trust Layer handles masking, toxicity checks and the audit trail for Agentforce.
</FaqItem>

<FaqItem question="Is Agentforce the same as Copilot?">
No. Copilot is Microsoft's brand. Microsoft's Sales agent, part of its Copilot offering for sellers, brings data from Dynamics 365 Sales or Salesforce into Outlook and Teams, where it drafts emails and captures action items from meetings. Agentforce runs inside Salesforce and can also answer your customers. Because the Sales agent can read Salesforce, the two can sit side by side. The [Copilot for sales guide](/blog/copilot-for-sales) covers Microsoft's side.
</FaqItem>

<FaqItem question="What is RAG in Agentforce?">
Retrieval augmented generation: before the model answers, relevant passages from your content are added to the prompt. In Agentforce, the Data Library indexes Knowledge articles, uploaded files and web search results for this. Adding a data library in Agentforce Builder sets up retrieval with default settings; Data 360 is where you fine-tune it.
</FaqItem>

<FaqItem question="Can Agentforce use Claude or OpenAI models?">
Yes. Salesforce's page on Agentforce Assistant describes Model Builder, which lets you bring your own large language model from providers such as Anthropic, Google, OpenAI and Hugging Face. The Trust Layer's zero data retention refers to Salesforce's agreements with its third-party model providers, so check how it applies to a model you connect yourself.
</FaqItem>
</Faq>
