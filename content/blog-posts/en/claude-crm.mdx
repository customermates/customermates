# Claude CRM: Connectors, Setup and Approvals

Claude has no CRM of its own, but it can work inside yours. Through a connector based on the Model Context Protocol (MCP), Claude finds, creates and updates records in the CRM and acts with the permissions of the person who connected it. HubSpot, Pipedrive, Zoho CRM, Capsule and Customermates offer such a connection today; Salesforce is piloting its own Claude plugin. What separates them is the plan you need on each side, whether Claude can delete, and where you decide which actions Claude may take without asking.

Below you will find a vendor table with sources, the setup in Claude and Claude Code, the permission settings that matter and the cost for a small team. Customermates publishes this guide and appears in it as one option, in its own labelled section.

<ArticleSummary title="At a glance">

## Four things people mean by "Claude CRM"

| What you mean | How it works | Fits | Watch for |
| --- | --- | --- | --- |
| Claude operates your existing CRM | The CRM vendor's MCP server or connector, added in Claude | Teams that already keep customers in a CRM | Plan requirements on both sides, missing actions such as delete |
| Claude works in the CRM's web interface | Claude in Chrome uses your logged-in browser session. [Anthropic's own example](https://academy.claude.com/use-cases/log-sales-calls-to-your-crm) matches calendar attendees to Salesforce contacts and drafts call logs | One person, occasional logging, no API setup | Slower than a connector, and it depends on the page layout |
| Claude is the CRM | Notes in a Claude project, or a Notion database that Claude updates through Notion's MCP server | One person with a short list of relationships | No shared permissions or audit history, and fields drift unless you define them |
| You build a CRM with Claude Code | Claude Code writes a custom application for you | Unusual data models, learning projects | You maintain login, backups, permissions and integrations yourself ([build or customize](/blog/customizable-crm)) |

Most search results for "Claude CRM" are about the first row, so the rest of this guide is about connectors.

## What Claude does once it is connected

The tools come from the CRM, not from Claude, so the exact list depends on the vendor. Across the connectors below, the everyday work looks like this:

- Answer questions from live records: "Which deals are in the Proposal stage, and who is the contact on each?"
- Create and link records after a call: a contact, its organization, a deal and a task.
- Change fields and add notes from a transcript or from notes you paste in.
- Where the CRM holds conversations, read a thread and prepare a reply.

Claude picks the tools and the order on its own. That works well for a handful of records per request. For hundreds of rows, vendor limits apply (HubSpot's connector creates or updates 10 records at a time in bulk), and an import is the better tool.

## How to connect Claude to a CRM

The steps are the same for any CRM with a remote MCP server. Where Customermates differs, it says so.

<Steps>
  <Step title="Check who can add the connector">
    On Free, Pro and Max you add it yourself; Free allows one custom connector. On Team and Enterprise, an Owner adds it under **Organization settings › Connectors**, and then each member connects individually.
  </Step>
  <Step title="Add the server address">
    In Claude, open **Customize › Connectors**, click **+**, choose **Add custom connector** and paste the vendor's MCP URL. Pipedrive's is `https://mcp.pipedrive.ai/mcp`. For Customermates, it is the address you open Customermates at, followed by `/api/v1/mcp`.
  </Step>
  <Step title="Sign in and approve">
    The CRM opens a sign-in window. In Customermates, the **Authorize access** screen names the connecting app and the host it sends access to; click **Approve**. From then on, Claude acts as you, with your role's permissions.
  </Step>
  <Step title="Set tool permissions">
    Select the connector under **Customize › Connectors** to see **Tool permissions**. Set read tools to **Always allow**, and leave anything that writes, sends or deletes on **Needs approval**. On Team and Enterprise, Owners can restrict a connector's actions for the whole organization, and members cannot override that.
  </Step>
  <Step title="Prove it with one read and one update">
    Ask a read-only question first, such as your open deals in one stage. Then change one field on a test record and add a note. Open the record in the CRM and check that the change is there. In Customermates, the record's **History** panel lists it, provided your role can read the audit log.
  </Step>
</Steps>

Customermates also has a shortcut: under **My Profile › API & Connectors**, click **Add** and choose **Claude** under **Quick connections**. **Add to Claude** then opens Claude's dialog with the address filled in (Claude web and Team only). The [connector guide](/docs/connect-custom-connector) has the details and a troubleshooting table.

### Claude Code, including Pipedrive

Claude Code adds remote MCP servers from the terminal. For Customermates, create a key under **My Profile › API & Connectors** (**Add**, then **Standard API key**; the key is shown once) and run:

```bash
claude mcp add --transport http customermates https://<your-customermates-address>/api/v1/mcp \
  --header "x-api-key: YOUR_KEY"
```

A server that signs in with OAuth instead of a key, such as Pipedrive's, is added without the header. You then complete the sign-in with `/mcp` inside Claude Code, as [Anthropic's Claude Code documentation](https://code.claude.com/docs/en/mcp) describes:

```bash
claude mcp add --transport http pipedrive https://mcp.pipedrive.ai/mcp
```

Pipedrive's guide covers the Claude app only, so try a read before you rely on Claude Code with it. The default scope is the current project. `--scope user` makes a server available in all your projects, and `--scope project` writes it to a `.mcp.json` file meant to be shared with your team, so keep API keys out of a file you commit. Codex, Cursor and the Gemini CLI are covered in the [CLI guide](/docs/connect-cli).

## Who controls what Claude writes

This is where setups differ most, and a wrong assumption here costs data.

- **The client is usually the gate.** The Customermates MCP server tells connected clients to confirm with you before they delete or send, but it does not enforce that: once Claude calls an allowed tool, the action runs. What protects you is **Tool permissions** in Claude. Capsule describes the same choice: you decide whether Claude checks with you before it makes changes.
- **Claude gets your permissions, not fewer.** A Customermates connector or API key inherits the permissions of the user behind it; there is no per-key scope. If Claude should do less than you can, connect it as a separate user with a narrower role (which takes a seat), or expose fewer tools with the toolsets parameter in the [MCP reference](/docs/mcp).
- **Sending is immediate.** If your CRM can send email or chat messages, a send call sends. Ask Claude to save a draft and send it yourself from the inbox.
- **Vendor guardrails vary.** HubSpot's connector cannot delete and applies conditional property and pipeline stage validation rules, but not association label validations. Capsule lists only create and update actions. Zoho's Data Operations server can delete, also in bulk.
- **What Claude reads goes to Anthropic.** Tool results become part of the conversation. Anthropic publishes separate [consumer and commercial terms](https://www.anthropic.com/legal/consumer-terms); check which ones cover your Claude plan, and whether you need a data processing agreement, before you connect customer data.

## What Claude plus a CRM costs

Claude prices from [claude.com/pricing](https://claude.com/pricing), checked on 8 October 2026, in USD with monthly payment: Pro is $20 per month, Team Standard seats are $25 per seat per month, for [teams of two or more](https://claude.com/pricing/team), and Team Premium seats are $125. On a yearly subscription, Anthropic charges $17 for Pro and $20 per Standard seat. Pro includes Claude Code.

| Team | Claude | CRM, with Customermates as the example |
| --- | --- | --- |
| Solo founder, records only | Free with one custom connector ($0), or Pro at $20 | Starter: [[commercial.price.starter.monthly]] per month |
| Three consultants, records only | Team Standard: 3 × $25 = $75 per month | Starter, 3 seats: [[commercial.price.starter.monthly.seats.3]] per month |
| Three consultants, email, LinkedIn and WhatsApp in the CRM | Team Standard: $75 per month | Pro, 3 seats: [[commercial.price.pro.monthly.seats.3]] per month |

Customermates bills monthly per user, with no yearly contract. When Claude works through MCP, the model runs on your Claude plan, so it uses no Customermates hosted AI credits. The self-hosted open-source core includes the MCP endpoint without licence fees, but not the inbox. With another vendor, add its seat price instead; HubSpot and Pipedrive list their connectors for all plans, and Pipedrive applies usage token limits per plan. Plan details are on the [pricing page](/pricing).

Customermates is not the right pick if you need a phone dialer, email sequences or a native mobile app, or if your team runs HubSpot or Salesforce and is happy with it. In that case, use the vendor's own connector from the table above.

## Frequently asked questions

<Faq>
<FaqItem question="Can Claude be used as a CRM?">
For one person with a short list, yes. A Claude project or a Notion database that Claude updates can hold contacts and notes. A team needs more than a chat history: shared permissions, defined fields and a record of who changed what. The common setup is a CRM that holds the records, with Claude as the interface on top.
</FaqItem>

<FaqItem question="Can I connect ChatGPT or Claude to my CRM?">
Yes, if your CRM offers an MCP server or a vendor connector. Claude adds it as a custom connector, and ChatGPT accepts custom MCP connectors as well. Which ChatGPT plans allow write actions is up to OpenAI, so check its help center. Customermates documents the setup for both in its connector guide.
</FaqItem>

<FaqItem question="How do I connect Pipedrive to Claude Code?">
Run `claude mcp add --transport http pipedrive https://mcp.pipedrive.ai/mcp`, then open `/mcp` in Claude Code and complete Pipedrive's sign-in. Pipedrive documents the Claude app only and names the connector "Pipedrive MCP BETA", so start with a read-only request.
</FaqItem>

<FaqItem question="Can Claude connect to Salesforce?">
Yes, through "Salesforce in Claude", the plugin from the Claudeforce partnership between Salesforce and Anthropic. Salesforce's page says it is available to select pilot customers; on 8 October 2026 it still named September 2026 for an open beta, so check the page for the current status. Claude in Chrome can also work in the Salesforce web interface through your browser session.
</FaqItem>

<FaqItem question="Is AI replacing the CRM?">
The interface is moving into AI clients, the record is not. Every connector in this guide reads and writes the CRM's own database with the user's permissions. Salesforce describes Claudeforce as putting your data to work inside Claude, governed by the permissions and business rules your company already runs on.
</FaqItem>

<FaqItem question="Do I need a paid Claude plan?">
Not for one custom connector, because Free allows one. HubSpot's connector requires Pro, Max, Team or Enterprise. On Team and Enterprise, an Owner adds connectors for the organization and can restrict their actions for everyone.
</FaqItem>
</Faq>
