# Excel CRM Template: A Free Six-Sheet Layout You Can Import Later

An Excel CRM template supports customer relationship management with one sheet for each kind of record (companies, contacts, deals, activities) and one sheet that counts and sums them. The layout below is free to copy: type the headers into a blank workbook, add the dropdowns and paste the formulas. It holds up for one to three people who keep a single copy of the file, and each sheet is arranged so it can later go into a CRM as an import, without retyping a row.

Customermates publishes this guide and is the CRM in the import example. The workbook itself needs nothing but a current version of Excel.

## Where can I download the checked CRM workbook?

Download the [free Excel CRM workbook in English](/templates/crm-template-en.xlsx), or the [German CRM workbook](/templates/crm-template-de.xlsx). It is an original, compact example with six working sheets plus a Readme: Companies, Contacts, Deals, Activities, Dashboard and Lists. It is separate from the fuller column-by-column layout below; do not paste the formulas below into the download without checking their column references.

The example keeps **one customer and two jobs** together with stable source IDs. Both `JOB-001` and `JOB-002` point to `C-001`, even if you rename the customer. Its dates are date cells, its states use dropdowns and its customer lookup uses the source ID. The dashboard contains 9,000 EUR in example opportunities and 4,050 EUR weighted value: 7,200 × 50% plus 1,800 × 25%. The two open next steps remain separate activities.

Checked on 29 October 2026: we wrote and reopened both XLSX files with ExcelJS, checked sheet names, date cells, lookup references and stored formula results, and checked that they contain no macros or external workbook connections. We did not perform a visual session in Microsoft Excel or LibreOffice. Open your copy in your spreadsheet application, recalculate it and confirm the two example totals before replacing the fictional rows. Do not add several currencies into one total without an explicit conversion policy.

## Four layout rules before the first row

1. **One header row, one row per record.** No merged cells, no blank rows, no subtotals inside the data.
2. **Make each sheet an Excel table.** Select the range, press Ctrl+T and name it under Table Design › Table Name: `Companies`, `Contacts`, `Deals`, `Activities`. The formulas below use those names, and tables grow with new rows.
3. **Give every fixed list a dropdown.** Use Data › Data Validation, Allow: List, with a table on the Lists sheet as the source. Microsoft's [drop-down guide](https://support.microsoft.com/en-us/excel/get-started/create-a-drop-down-list) notes that dropdowns based on a table update by themselves when you add or remove items.
4. **Keep a stable source ID as well as readable names.** The layout below uses exact names for the native XLSX link mapping. The compact download also keeps source IDs for lookups and a later JSON/API mapping. Names help people choose a record; preserve the source-to-record-ID map when names change.

## The template, sheet by sheet

### Lists

Small tables that feed the dropdowns. The stage table also carries a win probability, which the Deals sheet looks up.

| Table | Columns | Starting values |
| --- | --- | --- |
| `Stages` | Stage, Probability | Prospecting 10%, Qualification 20%, Demo 40%, Proposal 60%, Negotiation 80%, Won 100%, Lost 0% |
| `ContactTypes` | Contact type | Lead, Customer, Partner, Former customer |
| `Sources` | Source | Referral, Website, LinkedIn, Event, Outbound |
| `ActivityTypes` | Type | Call, Email, Meeting, LinkedIn, WhatsApp |
| `Team` | Name | Full name of everyone who owns records |

These stages and probabilities are an example. Customermates has no preset stages: create the same options on the Stage field of your deals list in Configure (or let AI setup build them in the cloud), and the Stage column imports later without renaming. Treat the percentages as a first guess and replace them once you have a few months of won and lost deals to count.

### Companies

Columns: Company (unique name), Industry (dropdown), Website, City, Country, Owner (dropdown from `Team`), Notes. Decide once whether you write "Ltd" or "Limited" and keep to it. Two spellings are two companies to every lookup and every importer.

### Contacts

| Column | Content | Example |
| --- | --- | --- |
| A First name | Text | Sarah |
| B Last name | Text | Okafor |
| C Company | Dropdown from the Company column of `Companies` | Brookfield Architects |
| D Email | Text | sarah@brookfield-architects.example |
| E Phone | Stored as text, so the plus sign survives | +44 113 496 0000 |
| F LinkedIn | Profile URL | linkedin.com/in/sarahokafor |
| G Contact type | Dropdown from `ContactTypes` | Customer |
| H Source | Dropdown from `Sources` | Referral |
| I Owner | Dropdown from `Team` | Anna Berg |
| J Last contact | Date | 2025-11-28 |
| K Notes | Short text | Prefers calls before 10:00 |

Keep first and last name apart: most CRMs need both to create a person.

### Deals

| Column | Content | Example |
| --- | --- | --- |
| A Deal | Text | Brookfield Architects security review |
| B Company | Dropdown from `Companies` | Brookfield Architects |
| C Contact | Full name of the contact | Sarah Okafor |
| D Value | Number | 18000 |
| E Stage | Dropdown from `Stages` | Proposal |
| F Probability | Formula | 60% |
| G Weighted | Formula | 10800 |
| H Expected close | Date | 2026-01-31 |
| I Owner | Dropdown from `Team` | Anna Berg |
| J Next step | One sentence | Send revised scope |
| K Next step date | Date | 2025-12-04 |
| L Closed on | Date, filled when Won or Lost | |
| M Loss reason | Dropdown: Price, Timing, Competitor, No decision | |

Enter the two formulas once in the first data row; the table fills them down:

```
F  Probability   =XLOOKUP([@Stage],Stages[Stage],Stages[Probability],0)
G  Weighted      =[@Value]*[@Probability]
```

XLOOKUP needs Excel for Microsoft 365, 2021 or 2024. Microsoft's [XLOOKUP reference](https://support.microsoft.com/en-us/excel/functions/xlookup-function) says it is not available in Excel 2016 and 2019, where `=INDEX(Stages[Probability],MATCH([@Stage],Stages[Stage],0))` does the same.

To color past next-step dates red, select the data rows of column K and add a rule under Home › Conditional Formatting › New Rule › "Use a formula to determine which cells to format": `=AND($K2<>"",TODAY()>$K2)`. The color shows only to whoever opens the file. The workbook itself notifies nobody.

### Activities

One row per touch that mattered: Date, Contact (full name), Deal (name, or empty), Type (dropdown from `ActivityTypes`), Owner, Summary (one or two sentences on what was said and agreed) and Next step. It is the only sheet that answers "what did we last tell them?", so fill it right after the call.

### Dashboard

Five pipeline numbers:

```
Open pipeline      =SUMIFS(Deals[Value],Deals[Stage],"<>Won",Deals[Stage],"<>Lost")
Weighted pipeline  =SUMIFS(Deals[Weighted],Deals[Stage],"<>Won",Deals[Stage],"<>Lost")
Win rate           =COUNTIFS(Deals[Stage],"Won")/MAX(1,COUNTIFS(Deals[Stage],"Won")+COUNTIFS(Deals[Stage],"Lost"))
Won this month     =SUMIFS(Deals[Value],Deals[Stage],"Won",Deals[Closed on],">="&EOMONTH(TODAY(),-1)+1)
Past next steps    =COUNTIFS(Deals[Next step date],"<"&TODAY(),Deals[Stage],"<>Won",Deals[Stage],"<>Lost")
```

For the pipeline by stage, insert a PivotTable from `Deals` with Stage in Rows and Value in Values, and put a bar chart on it. Refresh it after edits.

Once two or more people sell, add a tracker per salesperson. Put the Monday of the week in B1 and one name per row from A4 down, then copy these row-4 formulas down:

```
Calls            =COUNTIFS(Activities[Owner],$A4,Activities[Type],"Call",Activities[Date],">="&$B$1,Activities[Date],"<"&$B$1+7)
Meetings         =COUNTIFS(Activities[Owner],$A4,Activities[Type],"Meeting",Activities[Date],">="&$B$1,Activities[Date],"<"&$B$1+7)
Open pipeline    =SUMIFS(Deals[Value],Deals[Owner],$A4,Deals[Stage],"<>Won",Deals[Stage],"<>Lost")
Won this week    =SUMIFS(Deals[Value],Deals[Owner],$A4,Deals[Stage],"Won",Deals[Closed on],">="&$B$1,Deals[Closed on],"<"&$B$1+7)
Past next steps  =COUNTIFS(Deals[Owner],$A4,Deals[Next step date],"<"&TODAY(),Deals[Stage],"<>Won",Deals[Stage],"<>Lost")
```

Plenty of calls with a flat pipeline points to a qualification problem. A rising count of past next steps points to a follow-up problem. Use the tracker for coaching, not as a public ranking, or the activity counts start to inflate.

| If this describes you | Use | Watch for |
| --- | --- | --- |
| One person, a few hundred contacts, most conversations by email | This Excel template on your own machine | Keep one copy and back it up weekly |
| Two or three people on Microsoft 365 who edit the same file | The workbook in OneDrive or SharePoint with [co-authoring](https://support.microsoft.com/en-us/excel/get-started/collaborate-on-excel-workbooks-at-the-same-time-with-co-authoring) | Needs a Microsoft 365 subscription and .xlsx, .xlsm or .xlsb |
| A team that lives in Google Workspace | The same layout in Google Sheets, see the [Google Sheets CRM guide](/blog/google-sheets-crm) | Re-check each formula after rebuilding it |

## Where a spreadsheet CRM stops working

Size is rarely the reason; these limits show up first.

- **Links are text.** Rename a company and every contact, deal and lookup that used the old name points nowhere until you run Find and Replace over the workbook.
- **The file waits for you.** A red date helps only the person who opens the sheet, and messages from email, LinkedIn or WhatsApp arrive only when someone types a summary.
- **Access is all or nothing.** Anyone who can open the workbook can read every sheet.
- **Personal data spreads over copies.** Under the [GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj), a person may ask what you hold about them (Article 15) and have it erased (Article 17). With a workbook, that means every copy on every laptop and in every sent folder.

## When to switch: a checklist

- Two or more people update the same deals in a normal week.
- A follow-up slipped because its date sat in a column nobody filtered.
- You copy messages from LinkedIn or WhatsApp into the sheet, or you have quietly stopped doing it.
- Fixing the Dashboard takes longer than reading it.
- Someone asks who can see the customer list, and the honest answer is "anyone with the file".

If two of these are true, I would move. One alone is usually fixable inside the workbook.

## Moving the template into Customermates

Customermates imports Excel workbooks (.xlsx), one list at a time. CSV files are not accepted, so save them as .xlsx first. The [import documentation](/docs/app-records#how-do-i-import-or-export-records) has the full rules. Here is where the template's columns land:

| Template column | Customermates field |
| --- | --- |
| Company | Organization name |
| First name, Last name | First name and Last name |
| A contact's or deal's Company | Organizations, matched by name |
| A deal's Contact | Contacts, matched by full name |
| Email, Phone, LinkedIn | Contact details on the contact |
| Industry, Contact type, Source, Loss reason | Single choice custom fields |
| Website; City, Country, Next step | Web address custom field; Text custom fields |
| Last contact, Expected close, Next step date, Closed on | Date custom fields |
| Stage | The deal's Stage field |
| Value | Line items, see step 2 |
| Probability, Weighted | Left out: the stage's probability sets the weighted value |
| Owner | Assigned, matched by the team member's full name |
| Notes | Notes |
| Open next steps from Activities | Tasks |

<Steps>
  <Step title="Create the custom fields first">In **Configure**, open the list and choose **Add**, then **Field**. For each dropdown column, create a Single choice field whose option labels match your Lists sheet exactly; the import flags any cell that is not an option. Inspect the stage field and probabilities in your workspace; AI setup and existing workspaces can use different lists and options. Create or adjust the needed options in Configure rather than assuming they match this example.</Step>
  <Step title="Decide how deal values come in">A deal's value in Customermates is the sum of its line items, each a service price times quantity. Import your price list into **Services** first (Name and Price are required), then add line items with their quantities on each deal. If every deal has its own price, a Money input field can keep the number. It does not automatically replace the existing line-item calculation; a schema manager must preview and deliberately change the value and weighting configuration if that is the intended model.</Step>
  <Step title="Import in dependency order">Services, then companies into Organizations, then contacts, then deals. Links are matched by name, ignoring case, so a company must exist before a contact can point to it, and a name that matches no record or several is flagged. A comma separates names within a cell, so a firm called "Hale, Brook and Partners" needs a rename before the import or a link set by hand afterwards.</Step>
  <Step title="Run the wizard">On each list, open **More actions**, choose **Add from file** and pick the file. The wizard asks which sheet to import, so the workbook can keep its other sheets; save it as .xlsx. A file can currently hold up to 10 MB and 5,000 rows. Match each column to a field; email addresses, phone numbers and LinkedIn profiles go into the contact's Contact details field.</Step>
  <Step title="Fix or skip problem rows">The check lists every problem by row before anything is added. Fix the cells in Excel and check again, or import the rest and skip those rows. An import has no undo, so run ten rows first.</Step>
  <Step title="Turn open next steps into tasks">From Activities, bring over only open next steps, as tasks linked to the deal and contact and assigned to the owner. Tasks have no due date field, so add a Date custom field for the date. Older history can go into the deal's Notes or stay in the archived workbook.</Step>
</Steps>

### What replaces the dashboard and the red cells

- **The pipeline** becomes the Deals list as a board grouped by Stage, with total and weighted value per column; the [pipeline view](/features/pipeline) shows it.
- **Past next steps** become a personal saved view of deals with a Next step date, sorted oldest first. For deals nobody has touched, filter **Updated at** with **Older than…** and 14 days.
- **The morning check** can run in Customermates Cloud. Customermates has no reminders or notifications, but a routine set to run every day at 08:00 can work through an instruction like this one, using hosted AI credits:

> List my open deals whose Next step date is today or earlier. For each one, create a task linked to the deal, assigned to me, named "Follow up" plus the deal name. Do not send or draft any messages.

A routine acts with its owner's access, and Mate sends messages when told to, so the instruction has to say what it must not do. Starter includes [[commercial.entitlement.starter.includedRoutinesPerUser]] routine per user and Pro [[commercial.entitlement.pro.includedRoutinesPerUser]]; the [routines documentation](/docs/app-routines) lists the run limits.

- **The Activities sheet** gives way, on Pro and higher, to the [unified inbox](/features/unified-inbox), which keeps email, LinkedIn, WhatsApp, Instagram and Telegram threads with the contact. Pro includes [[commercial.entitlement.pro.includedAccountsPerUser]] connected account per user, Business [[commercial.entitlement.business.includedAccountsPerUser]]. Starter has no inbox.

## FAQ

<Faq>
<FaqItem question="Can you build a CRM in Excel?">
Yes, for a small team. The six-sheet layout above covers companies, contacts, deals, activities and a dashboard. What Excel cannot do on its own is notify anyone, keep links intact when a name changes, or pull in conversations. Excel is a spreadsheet, not a CRM; Microsoft sells its CRM separately as [Dynamics 365 Sales](https://www.microsoft.com/en-us/dynamics-365/products/sales).
</FaqItem>

<FaqItem question="Is there a free Excel CRM template?">
The layout in this article and the downloadable XLSX example above are free and need nothing except a compatible spreadsheet application. If you download a template elsewhere, check three things before you enter data: one record per row, contacts separate from companies, and no merged cells. A template that fails them is hard to import into a CRM later.
</FaqItem>

<FaqItem question="How many contacts can an Excel CRM handle?">
A worksheet holds 1,048,576 rows according to Microsoft's [Excel specifications](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits), and a Google Sheets file up to 20 million cells according to [Google's file limits](https://support.google.com/drive/answer/37603). The practical limit is people, not rows: the checklist above applies long before the file fills up. Customermates currently reads up to 5,000 rows per import file, so split larger sheets.
</FaqItem>

<FaqItem question="Can a CRM stay in sync with my Excel file?">
Not Customermates. Import and export are file transfers, one list at a time, with no live sync and no CSV. A round trip works: export a list to .xlsx (up to 5,000 records), edit it in Excel and import it again as **Existing records**, and its Record ID column updates those records instead of creating duplicates.
</FaqItem>

<FaqItem question="What should a sales tracking spreadsheet for reps include?">
One row per salesperson per week: calls, meetings, open pipeline, revenue won and the number of deals with a past next step. Calculate every cell from the Deals and Activities sheets with COUNTIFS and SUMIFS, as in the tracker above, so nobody types numbers that drift from the data.
</FaqItem>
</Faq>
