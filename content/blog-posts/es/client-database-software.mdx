# Base de datos de clientes: qué tipo de software encaja con tu equipo

El software de base de datos de clientes, también llamado programa de base de datos de clientes, guarda un registro por cliente: quién es, a qué empresa pertenece, qué se ha acordado con él y qué trabajo sigue abierto, de forma que todo el equipo pueda encontrarlo. Para un [pequeño negocio de servicios](/for/professional-services), la respuesta práctica suele ser un CRM ligero, porque vincula personas, empresas y trabajo en curso sin que tengas que construir nada. Una base de datos sin código como Airtable o Ninox encaja cuando tus registros no se parecen a clientes y oportunidades. Y una hoja de cálculo o una agenda de contactos sigue valiendo si trabajas solo con una lista corta.

A continuación verás en qué se diferencian los términos, los cinco tipos de software que aparecen en esta búsqueda, cómo una ficha de cliente se convierte en registros vinculados, qué permite cada plan gratuito antes de detenerse, una prueba de 30 minutos que puedes hacer con cualquier versión de prueba y una base de datos de clientes montada en Customermates. Customermates publica esta guía y aparece en su propia sección señalada como tal. Los datos de los proveedores se comprobaron el 11 de noviembre de 2026 en las páginas de cada uno, enlazadas al final.

Usa la [plantilla de lista de contactos](/blog/contact-list-template) para un directorio pequeño y compartido con un responsable con nombre y un siguiente paso, antes de decidir si lo pasas a un CRM.

La gestión de una base de datos de clientes también necesita un responsable operativo: decide quién corrige los duplicados, revisa los accesos y elimina la información que ya no hace falta. Comprar software no asigna esa responsabilidad por ti.

## Base de datos de clientes, base de datos de CRM, gestión de clientes: qué significa cada término

Estas palabras se solapan, y los proveedores las usan con holgura. Así las usa esta guía, y adónde ir para los temas vecinos.

| Término | Qué significa aquí | Más información |
|---|---|---|
| Base de datos de clientes | Los registros guardados sobre tus clientes: quiénes son, cómo contactarlos, a qué empresa pertenecen, qué se acordó. Esta página. | Estás aquí |
| Base de datos de CRM | El modelo de datos vinculado que hay detrás de un CRM: personas, empresas, oportunidades, tareas y el historial de cada registro. | [Guía de la base de datos de CRM](/blog/crm-database) |
| Gestión de clientes | Trabajar con los clientes día a día: responsables, siguientes pasos, conversaciones. Como software se llama gestión de clientes o de contactos. | [Software de gestión de clientes](/features/contact-management) |
| Lista de clientes o fichero de tarjetas | Una lista plana o un fichero con una línea o una tarjeta por cliente y sin vínculos entre ellos. | [Plantilla de lista de contactos](/blog/contact-list-template) |

Una base de datos de clientes es el lugar compartido donde cada cliente tiene exactamente un registro. La pregunta a la que responde esta guía es cuánta estructura necesitas alrededor de ese lugar.

## Cinco tipos de software que se venden como base de datos de clientes

Busca software de base de datos de clientes y encontrarás CRM, creadores de bases de datos, agendas de contactos, herramientas de contabilidad con una lista de clientes y suites sectoriales para estudios o consultas. Resuelven problemas distintos, así que elige primero el tipo y después el producto.

| Tipo | Ejemplos | Fuerte en | Dónde se queda corto | Encaja cuando |
|---|---|---|---|---|
| Hoja de cálculo | Excel, Google Sheets | Gratis, conocida, lista en minutos | Sin vínculo entre una persona y su empresa, sin historial por cliente, las copias se desincronizan en cuanto edita más de una persona | Trabajas solo y la lista cabe en una pantalla |
| Agenda o app de contactos | Google Contactos, contactos de Outlook, contactos del teléfono | Gratis, ya está en tu teléfono y en tu correo, rápida de buscar | Pensada para buscar a una persona, no para seguir lo acordado ni lo que sigue abierto; sin oportunidades, sin historial por cliente | Trabajas solo y necesitas contactar con personas, no gestionar trabajo con ellas |
| Base de datos sin código | Airtable, Ninox, bases de datos de Notion | Tú diseñas las tablas, los campos y las relaciones | También construyes y mantienes tú la lógica de clientes; los planes gratuitos limitan los registros | Tus registros son inmuebles, equipos o eventos más que clientes y oportunidades |
| CRM | HubSpot, Zoho CRM, Pipedrive, Customermates | Personas, empresas, oportunidades e historial de conversaciones vinculados desde el primer día | Tipos de registro básicos fijos; los planes de pago se cobran por usuario | Los clientes traen trabajo continuo, propuestas o negocio recurrente |
| Software de contabilidad o sectorial | Herramientas de facturación, sistemas de reservas para estudios, software de consultas | La lista de clientes está ligada a la facturación, las reservas o las citas | Poco espacio para el historial de la relación y las conversaciones | Tu trabajo con clientes es sobre todo facturar o programar citas |

Una trampa habitual en los pequeños negocios: quieren una lista sencilla de clientes y solo encuentran suites sectoriales completas con reservas y pagos. Si necesitas reservas, esa suite es la categoría adecuada. Si necesitas saber quiénes son tus clientes y qué has acordado con ellos, un CRM o una base de datos es la herramienta más ligera. Y si quieres ver primero hasta dónde llega una hoja bien construida, la [plantilla de CRM en Excel](/blog/excel-crm-template) y la [guía de CRM en Google Sheets](/blog/google-sheets-crm) son puntos de partida razonables. Si una persona solo necesita consultar nombres y números, la [guía del rolodex digital](/blog/digital-rolodex) compara agendas de contactos.

## De la ficha de cliente a los registros de cliente: qué va dónde

Si tus clientes viven en fichas, en un rolodex o en una fila de una hoja de cálculo cada uno, pasar a una base de datos cambia una cosa: la ficha se divide en registros vinculados. Todo lo que hay en la ficha conserva su sitio.

| En la ficha o la fila | En la base de datos | Qué cambia |
|---|---|---|
| Nombre de la empresa y persona de contacto | Dos registros vinculados: una empresa y una persona | Una empresa puede tener varias personas, y su historial se conserva cuando un contacto se va |
| Dirección postal | Un campo de dirección en la empresa o en la persona | Las direcciones de facturación y de obra pueden diferir, y un campo se puede filtrar, a diferencia del texto libre de una ficha |
| Varios teléfonos y correos, tachados y reescritos | Varias entradas en los datos de contacto de una persona | El número antiguo y el nuevo conviven en lugar de que uno sobrescriba al otro |
| Cliente desde, último contacto | Campos de fecha | Puedes ordenar y filtrar por ellos, por ejemplo clientes sin contacto desde hace 90 días |
| Tipo de cliente anotado en el margen o en una pestaña de color | Un campo de selección única como Segmento | Una sola grafía en todas partes, así que el filtro funciona |
| Notas a mano con fechas | Notas en el registro, más el historial de conversaciones cuando la herramienta lo tiene | Se pueden buscar y las ve todo el equipo |
| Presupuesto o contrato grapado a la ficha | Un archivo adjunto al registro | Lo abres desde el cliente, no desde un archivador |
| «Volver a llamar en marzo» | Un campo de fecha para el siguiente paso y una vista ordenada por él | La lista solo te lo recuerda cuando la abres; un campo de fecha por sí solo no envía ningún recordatorio |

Ordena las fichas antes de pasarlas: decide qué grafía de cada cliente es la que cuenta y da a cada persona su propia fila. Así la importación va sin sobresaltos, primero las empresas y después las personas.

## Qué datos guardar de cada cliente: un ejemplo [#que-datos-guardar-de-cada-cliente]

Guarda solo lo que vayas a usar. Los datos de una buena base de datos de clientes caen en tres grupos:

- **Identificación:** nombre, empresa, correo y teléfono (con el prefijo del país).
- **Relación:** un segmento (por ejemplo iguala, proyecto o antiguo), desde cuándo es cliente, quién es el responsable y de dónde llegó.
- **Seguimiento:** el siguiente paso con una fecha real, las notas de lo acordado y los archivos (presupuesto, contrato).

Cualquier otro dato debe responder a una pregunta que vayas a hacer: si no vas a filtrar ni a informar por él, va en las notas. Guardar solo lo necesario, además, es un principio del RGPD (minimización de datos): nada se guarda «por si acaso». Así queda un ejemplo con tres clientes, tal como lo verías en una hoja de cálculo:

| Cliente | Empresa | Correo | Segmento | Cliente desde | Responsable | Siguiente paso |
|---|---|---|---|---|---|---|
| Marta Ruiz | Estudio Ruiz Arquitectos | marta@estudioruiz.example | Iguala | marzo de 2026 | Laura | Enviar la propuesta de ampliación, 18 de noviembre |
| Diego Fernández | Taller Fernández | diego@tallerfernandez.example | Proyecto | septiembre de 2026 | Pablo | Llamar para cerrar el presupuesto, 20 de noviembre |
| Carolina Soto | Soto y Asociados | carolina@sotoasociados.example | Antiguo | junio de 2026 | Laura | Retomar el contacto, 2 de diciembre |

En una hoja de cálculo, la columna «Empresa» es solo texto. En una base de datos o en un CRM, la empresa pasa a ser un registro propio vinculado a sus personas, como muestra la tabla anterior. Si quieres empezar con una hoja y pasar más adelante a un CRM, la [plantilla de CRM en Excel](/blog/excel-crm-template) trae estas columnas ya preparadas.

## La prueba de 30 minutos

Las listas de funciones se parecen. Estas comprobaciones separan las herramientas en media hora, con tus propios datos en cualquier versión de prueba o plan gratuito.

<Steps>
  <Step title="Importa 50 filas reales">Toma 50 filas de tu lista actual, incluida una desordenada con un nombre que falta. Observa cómo el importador asigna tus columnas y qué hace con la fila mala: rechazarla, saltársela o importarla rota sin avisarte.</Step>
  <Step title="Añade un duplicado a propósito">Crea una persona que ya existe, con la misma dirección de correo. Una buena herramienta te detiene o te avisa. Una floja crea un segundo registro y parte en dos el historial de ese cliente.</Step>
  <Step title="Vincula una persona a una empresa">Abre después la empresa. Debería listar a todas sus personas y su trabajo abierto sin que tengas que construir una búsqueda.</Step>
  <Step title="Añade los campos por los que de verdad filtras">Por ejemplo «Cliente desde» como fecha, «Segmento» como selección única y la dirección de facturación como texto. Después filtra por cada uno. Un campo por el que no puedes filtrar es una nota, no un dato.</Step>
  <Step title="Busca como lo harás con prisa">Busca por parte de un apellido, por una dirección de correo y por el nombre de una empresa. Cada búsqueda debería encontrar al cliente.</Step>
  <Step title="Exporta todo y abre el archivo">Si la exportación pierde los campos personalizados o el vínculo entre persona y empresa, tu salida también los perderá.</Step>
</Steps>

Si el equipo lo necesita, añade una sexta comprobación: da a un compañero acceso solo a sus propios clientes y mira qué puede seguir abriendo.

## Una base de datos de clientes en Customermates, paso a paso

Customermates es un CRM de código abierto y nativo de IA, desarrollado en Alemania para equipos pequeños que trabajan de cara al cliente, como consultores, agencias y fundadores. Esta es una base de datos de clientes para una pequeña consultora, montada tal como funciona hoy el producto. Un espacio de trabajo nuevo empieza sin listas: en Customermates Cloud, describe tu negocio en una frase y Mate construye las listas, el pipeline y el panel, y en una instancia autoalojada creas las listas en Modelo de datos. Después ajústalas así.

<Steps>
  <Step title="Pon a los registros los nombres que usas al hablar">En Modelo de datos, abre una lista y cambia su **Nombre** y su **Nombre en plural** en **General**: cambia Contactos por Clientes y Organizaciones por Empresas. Oportunidades puede pasar a ser Proyectos, y Tareas, Seguimientos. Sirve cualquier nombre, y se aplica a todo el espacio de trabajo.</Step>
  <Step title="Añade los campos por los que vas a filtrar">En Empresas, añade «Segmento» como campo de Selección única con Iguala, Proyecto y Antiguo, y «Cliente desde» como campo de Fecha. En Clientes, añade «Dirección de facturación» como campo de Dirección. Los teléfonos y los correos van en el campo Datos de contacto, que la lista de personas de la configuración con IA tiene desde el principio.</Step>
  <Step title="Importa primero las empresas y después las personas">Usa Más acciones › Añadir desde archivo con un libro de Excel (.xlsx o .xls) o un archivo CSV, una lista por importación. Importa las empresas y después la hoja de personas con una columna que contenga el nombre de la empresa de cada una: el asistente asocia las columnas de vínculo por nombre de registro, y las columnas de correo y teléfono se pueden asociar al campo Datos de contacto del cliente. Una hoja de cálculo puede pesar hasta 10 MB y cada hoja tener hasta 5.000 filas de datos.</Step>
  <Step title="Guarda tres vistas">En Empresas, «Clientes con iguala» filtra Segmento por Iguala. En Clientes, «Sin tocar en 90 días» filtra Actualizado el con Más antiguo que… 90 días. «Clientes sin empresa» filtra los clientes sin ninguna empresa vinculada. Comparte «Sin tocar en 90 días» con todo el equipo o con roles concretos, para que todos limpien la misma lista.</Step>
  <Step title="Conecta las conversaciones (Pro)">En Pro, cada usuario conecta [[commercial.entitlement.pro.includedAccountsPerUser]] cuenta, como Gmail, Outlook, LinkedIn o WhatsApp, y la [bandeja de entrada unificada](/features/unified-inbox) muestra esas conversaciones junto al cliente. Starter no tiene bandeja de entrada.</Step>
</Steps>

Limpia los archivos de origen antes de importar. El importador es estricto en algunas cosas:

- Pon una persona por fila y escribe cada empresa exactamente igual en los dos archivos: el asistente vincula las personas con las empresas por el nombre de registro de la empresa.
- Escribe los teléfonos con el prefijo del país, por ejemplo +49 o 0049. Un número nacional como 0621 123456 no tiene país implícito y se rechaza.
- Pon los nombres de columna en la primera fila. Un archivo CSV puede usar como delimitador una coma, un punto y coma, un tabulador o una barra vertical, y Excel con muchas configuraciones regionales europeas escribe puntos y comas.
- Después de la importación, abre la lista de filas fallidas, corrige en tu archivo de origen el motivo que indica e importa esas filas de nuevo.

Dos cosas que mostrará la prueba de arriba. Customermates deja que una misma dirección de correo pertenezca a varios registros, así que no impide ese duplicado: busca la dirección antes de añadir un cliente. Y la búsqueda encuentra a un cliente por su nombre o por cualquier dirección de correo o número de teléfono de sus datos de contacto. Las reglas de importación están documentadas en la [página de registros de la documentación](/docs/app-records).

**En Customermates Cloud, una rutina para clientes nuevos.** Mate, el asistente de Customermates Cloud, usa créditos de IA alojados. Una rutina ejecuta instrucciones guardadas según un horario o ante un evento de registro, como la persona que es su propietaria, y Starter incluye [[commercial.entitlement.starter.includedRoutinesPerUser]] rutina por usuario. Una rutina activada por **Registro creado** en Clientes podría llevar esta instrucción:

> Cuando se añada un cliente nuevo, comprueba si está vinculado a una empresa. Si no lo está, busca la empresa cuyo nombre coincida con el dominio de su dirección de correo y vincúlala. No crees nunca una empresa ni envíes nunca un mensaje. Si no coincide ninguna, añade una línea a las notas del cliente que lo indique.

Las dos últimas frases importan. Mate puede enviar mensajes cuando una instrucción lo pide, así que una rutina que solo deba ordenar registros tiene que decirlo. Si prefieres usar tu propio cliente de IA, Claude, ChatGPT y otros clientes MCP pueden leer y actualizar los mismos registros mediante MCP, y eso funciona también si autoalojas.

Una base de datos de clientes se justifica cuando cada cliente tiene un siguiente paso. En Pro, las conversaciones de LinkedIn y de correo se unen al registro del cliente, Mate o tu propio cliente de IA redacta la respuesta y el siguiente paso, y tú los revisas, los editas y los envías. Para probarlo con tus clientes reales, [empieza tu prueba de [[commercial.trial.days]] días](/auth/signup?job=followup). Sin tarjeta de crédito.

## Cuándo Customermates no es la base de datos de clientes adecuada

- **Solo necesitas nombres y direcciones para facturar.** Basta con la lista de clientes de tu software de contabilidad, y Customermates no tiene presupuestos ni facturación.
- **Envías boletines.** En Customermates no hay correo masivo. Usa una herramienta de email marketing.
- **Gestionas reservas o citas.** Customermates no tiene reservas. Mira el software sectorial de tu oficio.
- **Trabajas sobre todo desde el móvil.** No hay app móvil nativa.
- **Tu modelo de datos no es de personas y empresas.** Customermates empieza sin listas y te deja crear las tuyas, pero está construido en torno a personas, empresas y oportunidades. Equipos, inmuebles o eventos sin nada que vender pueden encajar mejor en Airtable o Ninox.
- **Quieres autoalojar y conservar la bandeja de entrada.** El autoalojamiento es el núcleo AGPL con REST, webhooks y MCP. La bandeja de entrada unificada y Mate no forman parte de él.

## Cómo conseguir una base de datos de clientes [#como-conseguir-una-base-de-datos-de-clientes]

«Conseguir» una base de datos de clientes significa dos cosas distintas.

- **Reunir los clientes que ya tienes.** Están repartidos entre facturas, correos, el teléfono y hojas de cálculo. Junta todo en una sola lista, quita los duplicados, decide qué grafía de cada cliente es la que cuenta e impórtala una vez a la herramienta elegida.
- **Conseguir contactos nuevos.** Los más sólidos vienen de personas que te los dan: formularios de contacto o de suscripción, conversaciones en eventos, recomendaciones de clientes y contactos que tú mismo inicias por LinkedIn o por correo. Guarda de dónde llegó cada uno en un campo de origen.

Comprar una lista de contactos suele ser mala idea: los datos envejecen rápido y las personas de la lista no te han dado permiso para escribirles. El RGPD exige una base jurídica para tratar datos personales, y los correos comerciales tienen además normas propias en cada país (en España, la LSSI; en Latinoamérica, las leyes de cada país). Es información general, no asesoramiento jurídico: si dudas, consulta a un especialista antes de escribir a una lista que no hayas construido tú.

## Dónde viven los datos de los clientes

Una base de datos de clientes contiene datos personales. En la UE, un proveedor en la nube que los almacena por ti es un encargado del tratamiento, y el [artículo 28 del RGPD](https://eur-lex.europa.eu/eli/reg/2016/679/oj) exige un contrato con él, el contrato de encargado del tratamiento. Antes de importar, comprueba dónde se ejecuta la base de datos, quiénes son los subencargados y si puedes recuperar todos tus datos.

Ninox lista Alemania como región del servidor en su página de precios. Customermates Cloud tiene su base de datos principal configurada en la región AWS de Fráncfort; es un ajuste del producto, no una garantía contractual de residencia de los datos, y los subencargados del tratamiento, incluidos los proveedores estadounidenses, están en la [página de subencargados](/subprocessors). El [contrato de encargado del tratamiento](/dpa) es público. A la salida, Customermates exporta cada lista a un libro de Excel o a JSON, hasta 5.000 registros por exportación en la app; no hay una única exportación de toda la cuenta. El autoalojamiento pone la base de datos en tu propio servidor.

## Preguntas frecuentes

<Faq>
<FaqItem question="¿Qué es una base de datos de clientes?">
Una base de datos de clientes es el lugar compartido donde cada cliente tiene un registro: nombre, datos de contacto, empresa, el trabajo conjunto y notas sobre lo acordado. A diferencia de una simple lista de clientes, sus registros pueden vincularse entre sí, de modo que una empresa muestra a todas sus personas y su trabajo abierto. Una [base de datos de CRM](/blog/crm-database) añade encima oportunidades, tareas e historial de conversaciones.
</FaqItem>

<FaqItem question="¿Qué son los datos de un CRM?">
Son los registros que el CRM guarda sobre tu trabajo con clientes: personas, empresas, oportunidades o proyectos, tareas, notas, archivos y el historial de conversaciones, todos vinculados entre sí. La [guía de la base de datos de CRM](/blog/crm-database) explica cómo se organizan.
</FaqItem>

<FaqItem question="¿Qué debe contener una base de datos de clientes?">
Empieza por lo que consultas y filtras: nombre, empresa, teléfonos y correos, cliente desde, un segmento, quién es el responsable del cliente y el siguiente paso con una fecha real. Añade un campo solo cuando vayas a filtrar o a informar por él; todo lo demás va en las notas. La tabla de la sección de la ficha de cliente de arriba muestra dónde va cada elemento de una ficha en papel.
</FaqItem>

<FaqItem question="¿Cuál es el mejor software gratuito de base de datos de clientes?">
Depende de cuántas personas lo usen y cuántos registros guardes. Las herramientas gratuitas de HubSpot cubren 2 usuarios y 1.000 contactos, la edición gratuita de Zoho CRM 3 usuarios, Airtable Free 1.000 registros por base y Ninox Free 5 usuarios con 5.000 registros. Si puedes gestionar un servidor, EspoCRM, SuiteCRM y el núcleo de Customermates son de código abierto y sin coste de licencia. Customermates Cloud tiene un plan gratuito para [[commercial.limit.free.maxMembers]] persona y [[commercial.limit.free.maxRecords]] registros, sin bandeja de entrada, Mate ni rutinas, y una prueba de [[commercial.trial.days]] días.
</FaqItem>

<FaqItem question="¿Cómo creo una base de datos de clientes?">
Empieza con dos tipos de registro: las personas y las empresas para las que trabajan. Anota los campos por los que de verdad vas a filtrar y limpia después tu lista actual para que cada fila sea una persona y cada columna contenga un solo tipo de valor. Elimina duplicados, importa primero las empresas y después las personas, y guarda algunas vistas. La guía para [crear una base de datos de CRM](/blog/crm-database) cubre el modelo de datos con más detalle.
</FaqItem>

<FaqItem question="¿Cómo conseguir una base de datos de clientes?">
Reúne primero los clientes que ya tienes (facturas, correos, hojas de cálculo) en una sola lista limpia. Para contactos nuevos, apóyate en formularios con consentimiento, eventos, recomendaciones y conversaciones que inicias tú. Comprar listas suele salir mal: los datos están desactualizados y esas personas no te han dado permiso. Más detalle en la sección de arriba.
</FaqItem>

<FaqItem question="¿Cómo clasifico a los clientes en la base de datos?">
Con un campo de selección única, por ejemplo «Segmento» con opciones como Iguala, Proyecto y Antiguo, para que haya una sola grafía y el filtro funcione. Elige las categorías según cómo trabajas con ellos (tipo de contrato, tamaño o sector), no según una lista genérica. La [guía de segmentación de clientes](/blog/customer-segmentation) tiene más criterios.
</FaqItem>

<FaqItem question="¿Puedo usar Excel como base de datos de clientes?">
Sí, mientras una persona la mantenga y la lista siga siendo corta. Se rompe cuando dos personas editan copias distintas, cuando una empresa tiene varios contactos y cuando necesitas el historial de lo acordado. Una hoja limpia con un solo tipo de valor por columna también hace mucho más fácil el paso posterior a un CRM.
</FaqItem>

<FaqItem question="¿Cuál es la diferencia entre una base de datos de clientes y un CRM?">
Una base de datos de clientes guarda quiénes son tus clientes. Un CRM añade lo que está pasando con ellos: oportunidades o proyectos que avanzan por etapas, tareas de seguimiento y el historial de tus conversaciones. Si haces seguimiento de propuestas o de trabajo continuo, necesitas la parte de CRM.
</FaqItem>

<FaqItem question="¿Cuál es el mejor software para registrar nombres y direcciones de clientes?">
Si solo necesitas nombres y direcciones, basta con la lista de clientes de tu software de facturación o con una hoja de cálculo compartida. Elige un CRM cuando también hagas seguimiento de conversaciones y de trabajo por cliente. En Customermates, la dirección va en un campo de Dirección, que guarda una dirección postal y la abre en mapas.
</FaqItem>

<FaqItem question="¿Puedo alojar una base de datos de clientes en mi propio servidor?">
Sí, con un CRM de código abierto. EspoCRM y SuiteCRM tienen licencia AGPLv3, y EspoCRM funciona con PHP y MySQL, MariaDB o PostgreSQL. El núcleo de Customermates es AGPL-3.0 y funciona con Docker Compose y PostgreSQL 16. Customermates autoalojado incluye REST, webhooks y MCP para tu propio cliente de IA, pero no bandeja de entrada unificada ni Mate.
</FaqItem>
</Faq>
