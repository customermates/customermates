**Customermates est un CRM open source** pour les petites équipes : contacts, organisations, affaires et tâches dans des listes que vous configurez vous-même, avec REST, des webhooks et MCP pour les agents IA. Le cœur est publié sous licence AGPL-3.0 et public sur GitHub. Démarrez dans le cloud géré avec un essai Pro gratuit et sans carte bancaire, ou exploitez le cœur en auto-hébergement avec Docker Compose et PostgreSQL.

## Qu’est-ce qui est open source dans Customermates ?

Le code propre à Customermates en dehors de `ee/` est publié sous AGPL-3.0 uniquement. Le code de `ee/` relève de la Customermates Commercial License, à l’exception des éléments que la section 6 de `ee/LICENSE.md` maintient sous AGPL-3.0 : les parties livrées au navigateur (images, polices, CSS et JavaScript côté client).

La licence commerciale autorise à exécuter l’image officielle en mode auto-hébergé comme Community Build, y compris en production, tant que les fonctions cloud restent désactivées. Les conditions exactes figurent dans [`LICENSE`](https://github.com/customermates/customermates/blob/main/LICENSE) et [`ee/LICENSE.md`](https://github.com/customermates/customermates/blob/main/ee/LICENSE.md). Lisez les deux fichiers avant de modifier ou de redistribuer le code (informations de licence vérifiées le 29 octobre 2026).

Le CRM lui-même fonctionne de la même façon dans les deux cas : des listes pour les personnes, les organisations, les affaires ou les tâches, des champs personnalisés, des vues tableau, Kanban et calendrier, des tableaux de bord, des rôles et un journal d’activité. Les clients IA externes comme Claude ou ChatGPT passent par le [serveur MCP](/docs/mcp), avec les permissions de l’utilisateur sous lequel ils sont connectés.

## Cloud ou auto-hébergement : quelle voie vous convient ?

| Question                                               | Cloud géré                                                                         | Auto-hébergé                                                             |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Qui exploite l’application et la base de données ?     | Customermates                                                                      | Votre équipe, avec Docker Compose et PostgreSQL 16                       |
| Comment démarrer ?                                     | Créez un compte, essayez Pro pendant [[commercial.trial.days]] jours, sans carte bancaire | Téléchargez deux fichiers et lancez `docker compose up -d`         |
| Combien cela coûte-t-il ?                              | Dès [[commercial.price.starter.monthly]] par utilisateur et par mois               | Aucune facturation ; vous portez l’infrastructure et l’exploitation      |
| Périmètre fonctionnel                                  | Selon la formule                                                                   | Starter                                                                  |
| Boîte de réception et calendriers connectés            | Sur les formules éligibles à partir de Pro                                         | Non inclus                                                               |
| IA                                                     | Mate, l’assistant intégré, et des clients MCP externes                             | Des clients MCP externes avec votre propre fournisseur d’IA              |
| Configuration                                          | La configuration IA prépare l’espace de travail                                | Un nouvel espace de travail démarre sans listes                          |
| Mises à jour et sauvegardes                            | Customermates                                                                      | Votre équipe                                                             |

Le cloud convient si vous voulez travailler dès aujourd’hui avec de vrais clients sans exploiter de serveurs. La base de données de production principale est configurée dans la région AWS de Francfort ; c’est un paramètre choisi, pas une certification ni une garantie de résidence des données. La région, les fournisseurs et les garanties sont détaillés sur la page [CRM cloud](/features/cloud-crm).

L’auto-hébergement convient si votre équipe sait exploiter Docker et PostgreSQL et si les fonctions de Starter suffisent. Ce qui fonctionne exactement et ce qui manque est décrit sur la page [CRM auto-hébergé](/features/self-hosted).

## Comment essayer Customermates dans le cloud

<Steps>
  <Step title="Créez un compte">
    [Inscrivez-vous](/auth/signup) et créez votre premier espace de travail. Il
    bénéficie de [[commercial.trial.days]] jours de fonctions Pro, sans carte
    bancaire.
  </Step>
  <Step title="Décrivez votre espace de travail">
    Répondez à quelques questions sur vos clients, vos ventes et vos chiffres,
    ou faites lire votre site web. La configuration IA présente un plan avec
    listes, étapes du pipeline, champs, tableau de bord et pages de la base de
    connaissances, que vous validez ou ajustez.
  </Step>
  <Step title="Apportez vos propres données">
    Importez un classeur Excel (XLSX) ou démarrez avec des données d’exemple
    pour vérifier les vues et le pipeline.
  </Step>
  <Step title="Connectez votre propre IA">
    Connectez Claude, ChatGPT ou un autre client MCP si vous le souhaitez. Mate
    travaille dans l’espace de travail avec les permissions de l’utilisateur, et
    les actions sensibles nécessitent votre validation.
  </Step>
  <Step title="Choisissez une formule">
    Si Customermates vous convient, choisissez une formule. Rien n’est facturé
    sans validation du paiement ; après l’essai, l’espace de travail est mis en pause
    jusqu’au choix d’une formule.
  </Step>
</Steps>

Les formules et leur contenu sont présentés sur la page [tarifs](/pricing).

## Comment exploiter Customermates en auto-hébergement

Le [guide d’auto-hébergement](/docs/self-hosting) décrit la marche à suivre pas à pas : récupérez `docker-compose.yml` et `.env` depuis le dépôt avec `curl`, renseignez le mot de passe, le secret, `BASE_URL` et l’envoi des e-mails, puis lancez `docker compose up -d`. L’image est construite pour `linux/amd64` et `linux/arm64` et applique les migrations de base de données en attente à chaque démarrage.

Une instance auto-hébergée accueille autant d’espaces de travail que vous voulez, ne compte aucun siège et ne facture rien. En contrepartie, les mises à jour, les sauvegardes, les restaurations testées, TLS et la supervision vous incombent. L’auto-hébergement ne rend pas à lui seul un CRM conforme au RGPD : la configuration, les fournisseurs connectés, les contrats et l’exploitation restent sous votre responsabilité.

## Ce pour quoi Customermates n’est pas conçu

Customermates est un CRM ciblé, pas une suite de gestion. Il n’y a ni devis ni factures, ni séquences ni e-mails de masse, ni téléphonie ni SMS, ni applications mobiles natives, ni certification de conformité. Le SSO et la marque blanche ne sont pas développés. Si vous avez besoin d’un ERP, de comptabilité ou d’automatisation marketing dans le même système, une suite plus large vous conviendra mieux.

Si vous comparez plusieurs CRM open source côte à côte, notre [comparatif des CRM open source](/blog/open-source-crm) donne des critères sur la licence, le déploiement et l’effort d’exploitation. Des comparaisons directes couvrent [SuiteCRM](/compare/suitecrm-alternative), [EspoCRM](/compare/espocrm-alternative) et [Twenty](/compare/twenty-alternative).

## Questions fréquentes

<Faq>
<FaqItem question="Customermates est-il un CRM open source gratuit ?">
En auto-hébergement, Customermates ne facture rien ; vous ne payez que votre propre infrastructure, vos fournisseurs et votre temps d’exploitation. Le cloud géré coûte à partir de [[commercial.price.starter.monthly]] par utilisateur et par mois, facturé mensuellement, et commence par un essai gratuit de [[commercial.trial.days]] jours.
</FaqItem>

<FaqItem question="Ai-je besoin d’une carte bancaire pour l’essai ?">
Non. L’essai démarre avec votre premier espace de travail cloud et inclut les fonctions Pro. La facturation ne commence qu’à la validation du paiement.
</FaqItem>

<FaqItem question="Quelle est la différence entre un CRM open source et un CRM auto-hébergé ?">
Open source décrit la licence : vous pouvez examiner, modifier et redistribuer le code. Auto-hébergé décrit l’exploitation : l’application et la base de données tournent sur votre infrastructure. Avec Customermates, vous pouvez utiliser le cœur open source dans le cloud géré ou l’héberger vous-même.
</FaqItem>

<FaqItem question="Puis-je utiliser l’IA avec le CRM auto-hébergé ?">
Oui, via [MCP](/docs/mcp) avec un client IA externe et un fournisseur que vous choisissez et payez. Mate, les crédits IA hébergés et la configuration IA sont réservés au cloud.
</FaqItem>

<FaqItem question="Puis-je passer plus tard du cloud à l’auto-hébergement ?">
Oui, les enregistrements passent sous forme de classeurs XLSX, une liste à la fois. Pour les pièces jointes ou des volumes plus importants, prévoyez une migration via l’API REST. Il n’existe pas de transfert du compte complet.
</FaqItem>
</Faq>
