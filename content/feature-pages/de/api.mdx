## Was ist eine CRM API?

Eine CRM API (Application Programming Interface) ist eine Sammlung von Endpoints, die es externer Software ermöglichen, programmatisch auf Daten in Ihrem CRM zuzugreifen, diese zu erstellen, zu aktualisieren und zu löschen. Anstatt ausschließlich über die Benutzeroberfläche mit Ihrem CRM zu interagieren, ermöglicht eine API Entwicklern, individuelle Integrationen, automatisierte Workflows und Anwendungen zu erstellen, die direkt mit CRM-Daten arbeiten.

APIs sind unverzichtbar für Unternehmen, deren CRM als Teil eines größeren Technologie-Stacks funktionieren muss. Ob Sie ein individuelles Dashboard erstellen, Daten mit einem ERP- oder Buchhaltungssystem synchronisieren, Prozesse automatisieren, die über die Standard-UI hinausgehen, oder CRM-Funktionalität in eine andere Anwendung einbetten, die API ist das Tor, das dies ermöglicht.

Eine gute CRM API ist gut dokumentiert, versioniert, vorhersagbar und gibt Ihnen Zugang zu denselben Daten und Operationen, die in der Benutzeroberfläche verfügbar sind. Sie sollte sich wie ein erstklassiges Produktfeature anfühlen, nicht wie ein nachträglicher Anbau für Enterprise-Kunden.

## So funktioniert die CRM API in Customermates

Customermates bietet eine umfassende REST API, die Entwicklern vollen programmatischen Zugang zu allen CRM-Daten und -Operationen gibt. Der API-Zugang ist in jeder Preisstufe enthalten, ab 12 EUR pro Nutzer und Monat, ohne separate Entwickler-Stufe.

**REST-Architektur mit vorhersagbaren Endpoints.** Die API folgt Standard-REST-Konventionen mit vorhersagbaren URL-Strukturen, Standard-HTTP-Methoden (GET, POST, PUT, PATCH, DELETE) und JSON-Request- und Response-Bodies. Endpoints folgen einem konsistenten Muster: `/api/v1/{resource}` für Sammlungen und `/api/v1/{resource}/{id}` für einzelne Datensätze.

**Vollständige CRUD-Operationen über alle Entitäten.** Erstellen, lesen, aktualisieren und löschen Sie Datensätze für jede CRM-Entität: Kontakte, Organisationen, Deals, Services und Aufgaben, inklusive ihrer benutzerdefinierten Felder. Jede in der Benutzeroberfläche verfügbare Operation ist über die API verfügbar und gewährleistet Feature-Parität.

**OpenAPI-Spezifikation.** Die API ist mit einer vollständigen OpenAPI-3.1-Spezifikation dokumentiert, verfügbar unter `/api/v1/openapi`. Importieren Sie die Spec in Postman, Insomnia oder jeden beliebigen API-Client, um Endpoints interaktiv zu erkunden. Nutzen Sie die Spec zur automatischen Generierung von Client-Libraries in jeder Programmiersprache.

**Nativer MCP-Endpoint für KI-Agenten.** Über REST hinaus stellt Customermates einen nativen Model-Context-Protocol-(MCP-)Endpoint unter `https://customermates.com/api/v1/mcp` bereit, authentifiziert per `x-api-key`. KI-Agenten wie Claude, ChatGPT und Gemini verbinden sich damit und bedienen das CRM direkt. 46 Tools — 44 über zehn Toolsets plus zwei stets aktive Recherche-Konnektoren lassen sie Datensätze lesen und schreiben, Deal-Phasen verschieben und Follow-ups entwerfen, und, ab einer Messaging-Stufe, im gemeinsamen Postfach lesen und senden. Grenzen Sie die bereitgestellten Tools pro Client mit dem Parameter `?toolsets=` ein.

**Filterung, Sortierung und Paginierung.** Fragen Sie Datensätze mit flexiblen Filterparametern ab. Filtern Sie nach jedem Standard- oder benutzerdefinierten Feld, kombinieren Sie mehrere Bedingungen mit AND/OR-Logik, sortieren Sie Ergebnisse nach jedem Feld und paginieren Sie effizient durch große Ergebnismengen. Die API unterstützt Cursor-basierte Paginierung für konsistente Performance bei großen Datensätzen.

**Authentifizierung über API-Keys.** Authentifizieren Sie API-Anfragen mit sicheren API-Keys, die in Ihren Kontoeinstellungen generiert werden. Keys können jederzeit erstellt und widerrufen werden. Jeder Key erbt die Berechtigungen des Nutzers, der ihn erstellt hat, sodass der API-Zugang Ihre bestehende rollenbasierte Zugriffskontrolle respektiert.

**Webhooks für Echtzeit-Event-Streaming.** Konfigurieren Sie Webhooks, um Echtzeit-HTTP-POST-Benachrichtigungen zu erhalten, wenn Ereignisse in Ihrem CRM eintreten. Customermates sendet 26 Webhook-Events: 15 Datensatz-Ereignisse (erstellt, aktualisiert und gelöscht für jede der fünf Entitäten: Kontakte, Organisationen, Deals, Services, Aufgaben) plus 11 Messaging- und Kalender-Ereignisse. Jedes davon kann eine Zustellung an eine von Ihnen angegebene URL auslösen. Webhooks beinhalten Retry-Logik mit exponentiellem Backoff für fehlgeschlagene Zustellungen.

**Zugriff auf benutzerdefinierte Felder.** Alle benutzerdefinierten Felder sind vollständig über die API zugänglich, mit denselben Feldtypen, Validierungsregeln und Optionen wie in der Benutzeroberfläche. Lesen und schreiben Sie benutzerdefinierte Felddaten auf jedem Datensatztyp, um Integrationen zu ermöglichen, die mit Ihrem spezifischen Datenmodell arbeiten.

**Batch-Operationen.** Führen Sie Massen-Erstell-, Aktualisierungs- oder Löschoperationen in einem einzigen API-Call durch. Verarbeiten Sie Hunderte von Datensätzen gleichzeitig für Datenmigrationen, Massenanreicherung oder Massenaktualisierungen. Batch-Endpoints reduzieren die Anzahl der API-Calls und verbessern den Durchsatz für große Operationen.

**Rate-Limiting mit klaren Headern.** Die API implementiert faire Rate-Limits für konsistente Performance. Rate-Limit-Header in jeder Antwort zeigen Ihnen genau, wie viele Anfragen in Ihrem aktuellen Zeitfenster verbleiben, sodass Ihre Anwendungen sanft drosseln können.

**Versionierte API mit Abwärtskompatibilität.** API-Versionen folgen Semantic Versioning. Breaking Changes werden nur in neuen Hauptversionen eingeführt, und frühere Versionen werden mit dokumentierten Deprecation-Zeitplänen unterstützt. Ihre Integrationen werden nicht ohne Vorankündigung brechen.

## Zentrale Vorteile

**KI-Agenten bedienen Ihr CRM.** Der native MCP-Endpoint macht Customermates zu einem System, das KI-Agenten steuern können. Richten Sie Claude, ChatGPT oder Gemini darauf aus, und sie übernehmen die Dateneingabe: Datensätze anlegen, Deal-Phasen aktualisieren und Follow-ups entwerfen, über dieselbe berechtigungsgeprüfte API, die auch Ihr eigener Code nutzt. Die Pipeline bleibt aktuell, ohne dass jemand in Formulare tippt.

**Bauen Sie alles auf Ihrem CRM auf.** Die API entfernt die Einschränkungen der Standardoberfläche. Individuelle Dashboards, mobile Apps, Partner-Portale, kundenseitige Tools und interne Automatisierungsskripte sind alle möglich, wenn jede CRM-Operation programmatisch verfügbar ist.

**Automatisieren Sie über die UI hinaus mit Code oder n8n.** Während die n8n-Engine viele Automatisierungsszenarien visuell handhabt, ermöglicht die API individuelle Automatisierungslogik für Szenarien, die Code erfordern. Nutzen Sie n8n für No-Code-Workflows und die API für individuelle Skripte. Beide Ansätze arbeiten nahtlos zusammen.

**Daten im gesamten Tech-Stack synchronisieren.** Halten Sie Ihre CRM-Daten konsistent mit ERP-Systemen, Buchhaltungssoftware, Marketing-Plattformen, Support-Desks und Data-Warehouses. API und Webhooks zusammen ermöglichen Push- und Pull-Synchronisierungsmuster für Echtzeit- oder geplante Datenflüsse.

**CRM-Daten in individuelle Anwendungen einbetten.** Erstellen Sie interne Tools, Kundenportale oder Partner-Dashboards, die CRM-Daten in Echtzeit ziehen. Die API macht jede Anwendung CRM-fähig, ohne dass Nutzer den Kontext wechseln müssen.

**Entwicklerfreundlich ab dem ersten Tag.** Standard-REST-Konventionen, durchgängig JSON, OpenAPI-Spec, vorhersagbare Fehlerbehandlung und klare Rate-Limit-Header bedeuten, dass Ihre Entwickler sofort mit dem Bauen beginnen können. Keine proprietären Abfragesprachen, keine komplexen Authentifizierungsflüsse, keine steile Lernkurve.

**Open-Source-Transparenz.** Da Customermates Open Source ist, ist die API-Implementierung vollständig einsehbar. Entwickler können den Quellcode hinter jedem Endpoint lesen, genau verstehen, wie er funktioniert, und sogar Verbesserungen beitragen.

## Häufige CRM-API-Anwendungsfälle

**Individuelles Dashboard und Reporting.** Erstellen Sie interne Dashboards, die CRM-Daten mit Daten aus anderen Systemen kombinieren. Ziehen Sie Pipeline-Metriken, Aktivitätszahlen, Umsatzzahlen und Konversionsraten über die API und stellen Sie sie in einer maßgeschneiderten Oberfläche für Ihr Management dar.

**Website- und Formular-Integration.** Wenn ein Besucher ein Formular auf Ihrer Website absendet, nutzen Sie die API, um automatisch einen Kontakt und Deal in Customermates zu erstellen. Ordnen Sie Formularfelder CRM-Feldern zu, wenden Sie Lead-Scoring-Regeln an und leiten Sie den neuen Lead in die passende Pipeline.

**Datenmigration von anderen CRMs.** Nutzen Sie die API, um Daten aus HubSpot, Salesforce, Pipedrive oder Tabellen in Customermates zu migrieren. Erstellen Sie Migrationsskripte mit voller Kontrolle über Feldzuordnung, Deduplizierung und Datentransformation.

**ERP- und Buchhaltungssystem-Sync.** Synchronisieren Sie Deal-Daten mit Ihrem ERP- oder Buchhaltungssystem. Wenn ein Deal gewonnen wird, übertragen Sie Rechnungsdaten an Ihr Abrechnungssystem. Wenn eine Zahlung eingeht, aktualisieren Sie den Deal-Status im CRM. Bidirektionaler Sync hält beide Systeme aktuell.

**Webhook-gesteuerte Workflow-Orchestrierung.** Nutzen Sie Webhooks, um externe Prozesse auszulösen, wenn CRM-Ereignisse eintreten. Bei Deal-Gewinn die Bereitstellung in Ihrem Produkt starten. Bei Kontaktaktualisierung Änderungen an Ihre E-Mail-Marketing-Plattform synchronisieren. Bei überfälliger Aufgabe eine Slack-Benachrichtigung senden.

**Mobile und Desktop-Anwendungen.** Erstellen Sie individuelle mobile oder Desktop-Anwendungen, die über die API auf CRM-Daten zugreifen. Vertriebsteams im Außendienst können Datensätze über maßgeschneiderte Interfaces einsehen und aktualisieren.

**Datenanreicherungs-Pipelines.** Reichern Sie CRM-Kontakte mit Daten von Drittanbietern an. Nutzen Sie die API, um Kontakte zu lesen, Enrichment-Dienste aufzurufen und die angereicherten Daten zurückzuschreiben. Automatisieren Sie die Pipeline für zeitgesteuerte Ausführung oder lösen Sie sie via Webhooks bei neuen Kontakten aus.

**Testen und Entwicklung mit Sandbox-Daten.** Nutzen Sie die API, um Testumgebungen mit realistischen CRM-Daten zu füllen. Erstellen Sie automatisierte Testsuiten, die CRM-Datensätze erstellen, ändern und verifizieren, um sicherzustellen, dass Ihre Integrationen korrekt funktionieren.

## Warum Customermates für API-Zugang?

**Open Source und voll transparent.** Die API ist Teil der Open-Source-Codebasis von Customermates. Einsehen, verstehen, beitragen. Kein Black-Box-API-Verhalten.

**EU-gehostet und DSGVO-konform.** Der gesamte API-Verkehr wird über europäische Infrastruktur geleitet, mit vollständiger DSGVO-Konformität. Programmatischer Datenzugriff unterliegt denselben Datenschutzstandards wie die Benutzeroberfläche.

**Einfache, faire Preisgestaltung.** API-Zugang ist in jedem Plan enthalten, ab 12 EUR pro Nutzer und Monat. Keine separate API-Stufe, keine Kosten pro Anfrage, keine Premium-Entwicklerpläne. Jeder zahlende Nutzer erhält vollen API-Zugang.

**Self-Hosting für volle Kontrolle.** Wenn Sie Customermates self-hosten, läuft die API auf Ihrer Infrastruktur. API-Verkehr, Authentifizierung, Rate-Limits und Datenzugriff liegen vollständig unter Ihrer Kontrolle. Ideal für Organisationen mit strengen Sicherheits- oder Compliance-Anforderungen.

**Webhook-Zuverlässigkeit mit Retry-Logik.** Webhook-Zustellungen beinhalten automatische Retries mit exponentiellem Backoff. Zustellungsprotokolle ermöglichen die Inspektion von Payload und Antwort für jedes Webhook-Event, was das Debugging vereinfacht.

**n8n-Integration für hybride Workflows.** Kombinieren Sie API-Level-Kontrolle mit visueller n8n-Automatisierung. Nutzen Sie Ihr eigenes n8n für Standard-Workflows und die API für komplexe individuelle Logik. Beides ist ohne Aufpreis enthalten.
