**Cloud-based CRM software** is a customer-relationship system that the provider operates as a managed online service and that a team accesses through a browser. Customermates Cloud manages the application and database service while your team configures users, permissions, records, pipelines and connected providers.

## What Customermates Cloud actually includes

The managed product brings contacts, organizations, deals, services and tasks into one workspace. Teams can define typed custom fields, work in table, card and kanban views, inspect activity history and configure deal stages with probabilities. Dashboards show current operational values, including total and weighted deal or pipeline values.

REST, webhooks and MCP are available for supported integrations and externally operated workflows. These interfaces do not imply that every accounting, marketing, data or automation provider is built into Customermates.

| Area             | Current product surface                                                |
| ---------------- | ---------------------------------------------------------------------- |
| Customer records | Contacts and organizations with relationships and custom fields        |
| Sales work       | Deals, configurable stages, probabilities and weighted values          |
| Delivery context | Services and tasks linked to supported CRM records                     |
| Views            | Table, card and kanban where supported by the record type              |
| Interfaces       | REST, OpenAPI, webhooks and MCP                                        |
| Communication    | Unified inbox and read-only connected calendar on entitled cloud plans |

## Managed cloud or self-hosting?

Customermates offers a managed service and a separately operated open-source core. They share the core CRM, but they are not feature-identical editions.

| Decision                             | Managed cloud                                   | Self-hosted core                            |
| ------------------------------------ | ----------------------------------------------- | ------------------------------------------- |
| Application and database operation   | Customermates                                   | Customer or chosen operator                 |
| CRM records and views                | According to the cloud plan                     | Starter entitlement baseline                |
| Unified inbox and connected calendar | Included on entitled plans                      | Not included                                |
| AI access                            | Hosted Mate plus external MCP                   | External MCP only                           |
| Connected providers                  | Configured in the managed product               | Selected and operated by the customer       |
| Cost model                           | Monthly per user                                | Infrastructure, providers and operator time |

Choose the managed cloud when you want Customermates to operate the application and database and when your workflow needs cloud plan entitlements. Evaluate [self-hosting](/features/self-hosted) when operating Docker, PostgreSQL, updates, backups and connected providers is an intentional requirement rather than a generic preference.

## Database region, security and provider boundaries

The primary production database is configured in AWS Frankfurt (`eu-central-1`). This is a selected product setting, not a contractual promise that every service or transfer remains in that region. Application hosting, monitoring, connected-account transport and any provider selected by a customer have their own locations and transfer paths.

The [Data Processing Agreement](/dpa) documents measures including TLS in transit, encryption for the production database and backups at rest, role-based access, account-level segregation, monitoring and restoration procedures. It does not claim a security or compliance certification. The current [subprocessor list](/subprocessors) records the providers, purposes, known locations and transfer bases used by the managed service.

## AI and automation without false promises

Every managed-cloud plan includes the hosted Mate assistant and a plan-specific monthly hosted-AI credit allowance per active user. Mate works inside the CRM, uses the current user's permissions and applies separate confirmation controls to sensitive actions. The hosted capability can be disabled operationally, but it is no longer an unreleased product promise.

External AI clients can use the [Customermates MCP server](/docs/mcp) with a model provider and subscription selected by the customer. They use the customer's provider rather than Customermates hosted-AI credits. Hosted Mate and external MCP therefore share supported CRM tools and permission checks, but not their client, billing or confirmation path.

For automation, teams can call REST, receive webhooks, use MCP or connect a separately operated workflow tool such as n8n. Customermates does not include the n8n runtime, its third-party connectors or their provider contracts.

## Migration and reporting boundaries

Customermates has no dedicated CSV or CRM-record import/export workflow. Moving data from another CRM requires a separately designed REST or MCP process with explicit source mapping, validation, deduplication, retries and an agreed rollback.

Dashboards, activity history, stage probabilities and weighted deal or pipeline values help a team inspect the current workspace. They are not predictive close or revenue forecasts, lead scores, conversion analytics or pipeline-velocity analysis.

## Who Customermates Cloud fits

Customermates Cloud fits teams that want a managed, browser-based CRM for flexible records and pipelines, prefer explicit interfaces over a closed integration promise, and value a separately self-hostable open-source core.

It is not a fit when the requirement is a complete ERP, accounting, inventory, invoicing, helpdesk, call-center, predictive-analytics or turnkey migration suite. Those workflows require different products or a deliberately designed integration.

<FaqItem question="What is cloud-based CRM software?">
  It is CRM operated as a managed online service and accessed through a browser.
  “Cloud” describes deployment; “SaaS” describes how software is supplied and
  billed. They often overlap, but they are not definitions of the same thing.
</FaqItem>

<FaqItem question="What does Customermates operate in the managed cloud?">
  Customermates operates the application and database service. Customers still
  configure users, permissions, records, workflows and connected providers.
</FaqItem>

<FaqItem question="Where is Customermates Cloud data stored?">
  The primary production database is configured in AWS Frankfurt. This is a
  selected setting, not a contractual data-residency guarantee. Application
  hosting and subprocessors are documented separately and may involve other
  countries.
</FaqItem>

<FaqItem question="Can I self-host the same CRM?">
  You can operate the open-source core with Docker Compose and PostgreSQL.
  Self-hosting uses Starter entitlements and excludes the unified inbox,
  connected calendar, hosted Mate and hosted credits.
</FaqItem>

<FaqItem question="Does Customermates include data import or migration?">
  There is no dedicated CSV or CRM-record importer/exporter. Migration requires
  a separately designed REST or MCP workflow with explicit mapping, validation
  and deduplication.
</FaqItem>

<FaqItem question="What analytics does Customermates provide?">
  Dashboards, activity history, stage probabilities, weighted deal values and
  weighted pipeline totals. It does not provide predictive close or revenue
  forecasting, conversion analytics, pipeline-velocity analysis or lead scoring.
</FaqItem>

<FaqItem question="Does Customermates Cloud include AI?">
  Yes. Every cloud plan includes the hosted Mate assistant and a monthly
  hosted-AI credit allowance per active user. External AI clients can also use
  MCP with their own provider and do not consume those hosted credits.
</FaqItem>

<FaqItem question="Which plan includes the unified inbox?">
  Pro, Business and Enterprise in the managed cloud. Starter and self-hosted
  deployments do not include connected messaging accounts.
</FaqItem>
