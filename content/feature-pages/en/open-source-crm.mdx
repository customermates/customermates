**Customermates is not an open source CRM in the OSI sense; it is a source-available CRM** under the Sustainable Use License (fair-code). The source code is public on GitHub, you can self-host the free Community Edition for your own business, and you cannot resell it or host it for others. It is built for small teams: contacts, organizations, deals and tasks in lists you configure yourself, with REST, webhooks and MCP for AI agents. Start in the managed cloud with a free Pro trial and no credit card, or run the Community Edition self-hosted with Docker Compose and PostgreSQL. If you need an OSI-approved open source CRM, the [open source CRM comparison](/blog/open-source-crm) and the comparisons with [EspoCRM](/compare/espocrm-alternative), [SuiteCRM](/compare/suitecrm-alternative) and [Twenty](/compare/twenty-alternative) name the alternatives.

**Why follow-up is a cloud feature.** The follow-up work, LinkedIn and email conversations on each client and Mate drafting the replies, runs on Customermates Cloud from Pro. The self-hosted Community Edition is the same CRM with records, views, REST, webhooks and MCP for your own AI client, without the inbox and without Mate. Try the cloud first if drafted follow-up is what you want, and self-host when control over where the data runs matters more.

## Is Customermates open source?

No, not in the sense of the Open Source Initiative (OSI): an open source licence may not restrict use, and the Sustainable Use License does. Customermates is source-available and fair-code, the model n8n uses too. In practice:

- You can read, run and modify the code for your own internal business purposes, or for non-commercial and personal use.
- You can self-host the free Community Edition, in production too, as long as the cloud-only features stay off.
- You can distribute the code only free of charge and non-commercially, and you must keep the licence and copyright notices.
- You cannot resell it, host it as a service for third parties or white-label it. Embedding it in your own product is by agreement, and the Customermates branding stays visible.

First-party code outside `ee/` is licensed under the Sustainable Use License. Code in `ee/` uses the Customermates Enterprise License. The exact terms are in [`LICENSE.md`](https://github.com/customermates/customermates/blob/main/LICENSE.md) and [`ee/LICENSE.md`](https://github.com/customermates/customermates/blob/main/ee/LICENSE.md), with a plain-language FAQ in [`LICENSING.md`](https://github.com/customermates/customermates/blob/main/LICENSING.md). Read them before you modify or redistribute the code (licence details checked on 16 November 2026).

The CRM itself works the same way in both: lists for people, organizations, deals or tasks, custom fields, table, Kanban and calendar views, dashboards, roles and an activity log. External AI clients such as Claude or ChatGPT work through the [MCP server](/docs/mcp) with the permissions of the user they are connected as.

## Cloud or self-hosted: which route fits you?

| Question                                | Managed cloud                                                           | Self-hosted                                                     |
| --------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------- |
| Who runs the application and database?  | Customermates                                                           | Your team, with Docker Compose and PostgreSQL 16                |
| How do I start?                         | Sign up, try Pro for [[commercial.trial.days]] days, no credit card     | Download two files and run `docker compose up -d`               |
| What does it cost?                      | From [[commercial.price.starter.monthly]] per user per month            | No billing; you carry infrastructure and operating effort       |
| Feature set                             | By plan                                                                 | Starter                                                         |
| Inbox and connected calendars           | On eligible plans from Pro                                              | Not included                                                    |
| AI                                      | Mate, the built-in assistant, and external MCP clients                  | External MCP clients with your own AI provider                  |
| Setup                                   | The AI setup drafts the workspace                                       | A new workspace starts without lists                            |
| Updates and backups                     | Customermates                                                           | Your team                                                       |

The cloud fits when you want to work with real customers today and do not want to run servers. The primary production database is configured in AWS Frankfurt; that is a chosen setting, not a certification and not a residency guarantee. Region, providers and safeguards are covered on the [cloud CRM](/features/cloud-crm) page.

Self-hosting fits when your team can run Docker and PostgreSQL and the Starter feature set is enough. What exactly runs and what is missing is on the [self-hosted CRM](/features/self-hosted) page.

## How to run Customermates self-hosted

The [self-hosting guide](/docs/self-hosting) walks through it step by step: fetch `docker-compose.yml` and `.env` from the repository with `curl`, fill in the password, secret, `BASE_URL` and email delivery, then run `docker compose up -d`. The image is built for `linux/amd64` and `linux/arm64` and applies pending database migrations on every start.

A self-hosted instance holds any number of workspaces, counts no seats and bills nothing. In return you own updates, backups, tested restores, TLS and monitoring. Self-hosting does not make a CRM GDPR compliant on its own: configuration, connected providers, contracts and operations remain your responsibility.

## What Customermates is not built for

Customermates is a focused CRM, not a business suite. There are no quotes or invoices, no sequences or mass email, no telephony or SMS, no native mobile apps and no compliance certification. SSO and white-label are not built. If you need ERP, accounting or marketing automation in the same system, a larger suite fits better.

If you are weighing several open source CRMs side by side, our [open source CRM comparison](/blog/open-source-crm) gives criteria for license, deployment and operating effort. Direct comparisons cover [SuiteCRM](/compare/suitecrm-alternative), [EspoCRM](/compare/espocrm-alternative) and [Twenty](/compare/twenty-alternative).

## Frequently asked questions

<Faq>
<FaqItem question="Is Customermates a free open source CRM?">
It is free to self-host but not open source in the OSI sense: Customermates is source-available under the Sustainable Use License. Self-hosted, it bills nothing for your own business; you pay only for your own infrastructure, providers and operating time. The managed cloud costs from [[commercial.price.starter.monthly]] per user per month, billed monthly, and starts with a free [[commercial.trial.days]]-day trial.
</FaqItem>

<FaqItem question="Do I need a credit card for the trial?">
No. The trial starts with your first cloud workspace and includes Pro features. Billing starts only with the checkout.
</FaqItem>

<FaqItem question="What is the difference between an open source CRM and a self-hosted CRM?">
Open source describes the licence: an OSI-approved licence lets anyone inspect, modify and redistribute the code, including commercially. Self-hosted describes operations: the application and database run on your infrastructure. Customermates is self-hostable and source-available, not open source: you can read and run the Community Edition for your own business, or use the managed cloud, but you cannot resell it or host it for others.
</FaqItem>

<FaqItem question="Can I use it for my clients, resell it or host it for others?">
An agency can use Customermates as its own CRM for its own clients, and consulting, setup, workshops and training for clients are allowed. Deploying an instance for a client and charging for it needs an enterprise licence. Hosting it for third parties, reselling it and white-labelling are not allowed under the Community Edition, and embedding it in your own product is by agreement, with the Customermates branding staying visible.
</FaqItem>

<FaqItem question="Can I use AI with the self-hosted CRM?">
Yes, through [MCP](/docs/mcp) with an external AI client and a provider you choose and pay for. Mate, the hosted AI credits and the AI setup are cloud only.
</FaqItem>

<FaqItem question="Can I move from the cloud to self-hosted later?">
Yes, records move as XLSX workbooks, one list at a time. For attachments or larger data sets, plan a migration through the REST API. There is no whole-account transfer.
</FaqItem>
</Faq>
