## What CRM Email Integration Means Here

Customermates imports email threads from a connected Gmail, Microsoft Outlook, or IMAP account into its unified inbox. The same inbox also supports LinkedIn, WhatsApp, Instagram, and Telegram accounts. A connected account belongs to one user unless it is explicitly shared with the workspace.

This is an operational inbox, not an email-marketing suite. You can read synchronized threads, reply on the original channel, save or replace one local draft on an existing thread, change a thread's state, and link thread participants to CRM contacts. New outbound email can be sent immediately from a contact or through the API and MCP tools.

## How to Connect Email

1. Open **Profile → Connected accounts**.
2. Choose **Connect an account** and complete the provider's hosted authentication flow.
3. Select the folders to import when the account supports folder selection.
4. Open the [Inbox](/docs/app-inbox) to read and reply to synchronized threads.

Authentication happens in the provider connection flow. Customermates does not ask you to paste a Gmail or Microsoft password into the CRM.

## What Ships Today

**Unified email threads.** Incoming and outgoing email from connected accounts is synchronized into the inbox. Thread participants can be linked to CRM contacts, giving the team relationship context without claiming that every message is automatically attached to every deal or organization.

**Immediate replies and new messages.** Reply from an existing inbox thread, start a new email from a contact, or use the documented `send_email` API or MCP tool. Delivery is immediate.

**Drafts for existing threads.** Save one local draft per existing thread for a user to review. Saving again replaces that draft. Drafting does not deliver a message, and there is no draft object for a brand-new outbound email.

**AI-accessible messaging.** Authorized MCP clients can list connected accounts and threads, read messages, save a reply draft, and send email. Sending tools deliver immediately, so an agent should use the draft tool when human review is required.

**External AI clients draft and send.** Supported clients such as Claude, ChatGPT, and Gemini can use [[derived.mcp.tools.total]] MCP tools to read allowed context, draft one reply, and send where permitted. Customermates supplies the MCP endpoint, not the client, model, subscription, or autonomous result. Messaging tools are available on Pro and above.

**Customer-run automation.** Your own n8n instance or another automation service can use Customermates webhooks and APIs. Customermates does not host or bundle n8n, and the current product has no native scheduled-send, sequence, or bulk-campaign engine.

**Scheduled email through an external provider.** Write and review an individual draft in Customermates, then let a separately operated workflow and delivery provider schedule it. Customermates has no built-in send-later scheduler or campaign engine.

**Individual email sending.** Send a reviewed message to one recipient at a time through a supported account and keep it with the supported conversation history. Customermates does not provide bulk email or mass outreach; use a separate campaign provider for groups.

**Email sequences in an external provider with n8n.** Go beyond manual email with the n8n automation engine. Set up triggers that send emails automatically based on CRM events:

- When a deal moves to "Proposal Sent," send a follow-up template after 3 days if no reply
- When a new contact is created from a web form, trigger a welcome email sequence
- When a customer-defined task date is reached, let an external scheduler send a notification through an external provider
- When a deal is marked as won, send a thank-you email to the customer

Build these workflows visually in a separate n8n instance with no coding required. Campaigns and sequences run in that workflow and an external delivery provider, not directly inside Customermates.

Connected-account transport is provided through Unipile. The managed application database is configured in an EU region, while the legal pages disclose every relevant cloud subprocessor, processing location, and transfer safeguard. Do not treat that database setting as a promise that all processing stays in one country or never involves a US provider. See [Privacy](/privacy), [Subprocessors](/subprocessors), and the [DPA](/dpa).

The community self-hosted build does not include the Enterprise Edition unified inbox. A self-hosted operator that contracts for Enterprise Edition controls its own deployment but must still evaluate every connected provider and subprocessor it enables.

**Automated email workflows.** A separate n8n instance and external delivery provider can handle follow-ups, welcome emails, deal-stage notifications, and reminders. Your team focuses on high-value conversations while the external workflow handles routine messages.

**Better team collaboration.** When every email is logged in the CRM, any team member can pick up a conversation or cover for a colleague instantly. Deal handoffs become seamless because the incoming owner has full visibility into every prior communication.

**No tool switching.** Your team continues using Gmail or [Outlook](/features/outlook-integration) as they always have. The CRM works in the background to capture and organize everything. Alternatively, they can compose and send directly from the CRM. Either way, the communication is logged.

## Frequently Asked Questions

<Faq>
<FaqItem question="Which email accounts can I connect?">
Hosted connection flows support Gmail, Microsoft Outlook, and IMAP inboxes. A connected account belongs to one user unless it is explicitly shared with the workspace.
</FaqItem>

<FaqItem question="Can I track opens and clicks?">
No. The current product ignores provider open- and click-tracking events and does not expose engagement dashboards.
</FaqItem>

<FaqItem question="Can I schedule or bulk-send email?">
No. Customermates sends email immediately. Scheduled sends, bulk campaigns, reusable templates, and sequences require a separately operated system.
</FaqItem>

<FaqItem question="Can an AI agent draft without sending?">
Yes, on an existing thread. An authorized MCP client can save or replace one local reply draft for human review. There is no draft object for a brand-new outbound email, and sending tools deliver immediately.
</FaqItem>

<FaqItem question="Can I send email sequences through an external provider?">
Yes, through separate services. A customer-run n8n workflow can react to documented CRM events, while an external delivery provider owns delays, conditions, branching, sending, limits, logs, and costs. Customermates itself has no sequence engine.
</FaqItem>

<FaqItem question="Is the calendar two-way?">
No. Connected Google or Microsoft calendar events appear in a read-only CRM view. Customermates does not create, edit, or schedule provider-calendar events.
</FaqItem>

<FaqItem question="Is my email data stored in the EU?">
The managed Customermates database runs in an EU region. Application hosting, messaging services, and connected providers may process data elsewhere, including through US providers; this is not a compliance certification. Self-hosting excludes the cloud email integration.
</FaqItem>
</Faq>
