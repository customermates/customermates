    - icon: Rocket
      title: Schnelles Setup
      description: Erstellen Sie einen Arbeitsbereich und Datensätze ohne verpflichtendes Implementierungsprojekt. Aufwand für Migration und externe Integrationen hängt von Ihren Daten und Systemen ab.
    - icon: LayoutGrid
      title: Starker Funktionsumfang
      description: Das System enthält nur Funktionen, die Teams im Alltag wirklich benötigen. Keine überladenen Module, keine unnötigen Menüs und keine Funktionstiefe, die niemand nutzt.
    - icon: Zap
      title: Automationen mit n8n
      description: Webhooks und die REST API verbinden Customermates mit Ihrer eigenen n8n-Instanz und von dort mit hunderten Tools. Workflows können komplett individuell aufgebaut werden, vom Lead-Eingang bis zur Service-Abwicklung.
    - icon: ShieldCheck
      title: Offene Infrastruktur
      description: Die verwaltete Datenbank läuft in einer EU-Region und Anbieter stehen in der Subdienstleisterliste. Kern-CRM-Anwendung und PostgreSQL lassen sich mit Starter-Berechtigungen selbst hosten; verbundene Anbieter bleiben separat.
    - icon: Sparkles
      title: Einfache Bedienbarkeit
      description: Die Oberfläche ist bewusst reduziert und logisch aufgebaut. Nutzer finden alle wichtigen Funktionen sofort und können ohne Einarbeitung effizient arbeiten.
    - icon: DollarSign
      title: Keine versteckten Kosten
