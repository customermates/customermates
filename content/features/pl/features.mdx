  features:
    - icon: Rocket
      title: Szybka konfiguracja
      description: Utwórz przestrzeń roboczą i dodawaj rekordy bez obowiązkowego projektu wdrożeniowego. Nakład pracy na migrację i zewnętrzne integracje zależy od Twoich danych i systemów.
    - icon: LayoutGrid
      title: Skupiony zestaw funkcji
      description: Rekordy klientów, skrzynka odbiorcza, pipeline, pulpity i otwarte interfejsy. Pomija to, czego małe zespoły pracujące z klientami rzadko używają, jak oferty, fakturowanie i sekwencje e-mail.
    - icon: Zap
      title: Automatyzacja z n8n
      description: Webhooki i REST API łączą Customermates z Twoją instancją n8n, a stamtąd z narzędziami, które n8n obsługuje. Przepływy pracy budujesz samodzielnie, od pozyskiwania leadów po realizację usługi.
    - icon: ShieldCheck
      title: Otwarta infrastruktura
      description: Zarządzana baza danych działa w regionie AWS Frankfurt, a dostawcy, w tym z USA, są wymienieni na liście podprocesorów. Możesz samodzielnie hostować rdzeń aplikacji CRM na licencji AGPL i PostgreSQL z zestawem funkcji Starter; połączeni dostawcy pozostają osobno.
    - icon: Sparkles
      title: Łatwa obsługa
      description: Interfejs jest celowo uproszczony i logicznie zbudowany, więc funkcje, z których korzystasz codziennie, są pod ręką.
    - icon: DollarSign
      title: Bez ukrytych kosztów
      description: Opublikowane plany podają zakres Customermates i limit hostowanej AI; limit jest do wykorzystania, gdy Mate jest włączony, a aktualna dostępność zależy od środowiska hostowanego. Zewnętrzni klienci AI, automatyzacja, komunikatory i inni dostawcy mają własne subskrypcje i koszty użycia.
