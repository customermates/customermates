faq:
  title: Perguntas frequentes sobre automação com uma instância n8n separada
  faqs:
  - id: faq-1
    title: Preciso saber programar para usar o n8n?
    content: Fluxos básicos podem ser montados de forma visual, mas um fluxo de CRM confiável ainda precisa de alguém responsável por autenticação, mapeamento de campos, permissões, novas tentativas, erros e limites dos provedores. Transformações complexas podem exigir código.
  - id: faq-2
    title: Quais ferramentas posso conectar com o n8n?
    content: Use os nodes do catálogo de integrações atual do n8n, nodes verificados ou da comunidade que você tenha avaliado e requisições HTTP a APIs que você tem autorização para chamar. Disponibilidade e comportamento podem mudar, então confira a documentação atual do n8n e do provedor.
  - id: faq-3
    title: Conectar o n8n custa a mais?
    content: "A API REST e o MCP estão disponíveis em todos os planos, e os webhooks em todos os planos pagos e na hospedagem própria. O n8n é um produto separado que você hospeda ou assina, e os planos externos, os limites, os custos dos provedores e o uso continuam por sua conta."
  - id: faq-4
    title: Como começo com os fluxos do n8n?
    content: Instale o node da comunidade do Customermates publicado em uma instância do n8n que você opera, ou chame diretamente a API REST e os webhooks. Você projeta, implanta e mantém o fluxo.
  - id: faq-5
    title: Meus dados são compartilhados nos fluxos do n8n?
    content: Os fluxos rodam onde você implanta ou assina o n8n, e as ferramentas conectadas recebem os dados que o seu fluxo enviar. O banco de dados gerenciado do CRM roda na região AWS de Frankfurt; avalie cada provedor separadamente.
