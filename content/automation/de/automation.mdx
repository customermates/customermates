faq:
  title: Häufige Fragen zur Automatisierung mit einer separaten n8n-Instanz
  faqs:
  - id: faq-1
    title: Brauche ich Programmierkenntnisse für n8n?
    content: Einfache Abläufe lassen sich visuell zusammensetzen. Ein verlässlicher CRM-Workflow braucht dennoch Verantwortung für Authentifizierung, Feldzuordnung, Berechtigungen, Wiederholungen, Fehler und Anbieterlimits. Komplexe Transformationen können Code erfordern.
  - id: faq-2
    title: Welche Tools kann ich mit n8n verbinden?
    content: Nutzen Sie Nodes aus dem aktuellen n8n-Katalog, geprüfte Verified- oder Community-Nodes sowie HTTP-Aufrufe an APIs, die Sie verwenden dürfen. Verfügbarkeit und Verhalten können sich ändern; prüfen Sie die aktuelle Dokumentation von n8n und dem Anbieter.
  - id: faq-3
    title: Kostet die Anbindung von n8n extra?
    content: "Webhooks, REST API und MCP sind verfügbare Customermates-Schnittstellen in jeder Stufe. n8n ist ein separates Produkt, das Sie selbst hosten oder abonnieren; externe Tarife, Limits, Anbieterkosten und Nutzung bleiben bei Ihnen."
  - id: faq-4
    title: Wie starte ich mit n8n-Workflows?
    content: Installieren Sie den veröffentlichten Customermates-Community-Node in einer von Ihnen betriebenen n8n-Instanz oder nutzen Sie REST-API und Webhooks direkt. Sie entwerfen, betreiben und warten den Workflow.
  - id: faq-5
    title: Werden meine Daten bei n8n-Workflows weitergegeben?
    content: Workflows laufen dort, wo Sie n8n betreiben oder abonnieren; angebundene Tools erhalten die Daten, die Ihr Workflow sendet. Die verwaltete CRM-Datenbank läuft in einer EU-Region; prüfen Sie jeden Anbieter separat.
